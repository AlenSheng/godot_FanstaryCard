# 混沌领域 2D 分层背景

更新：2026-09-20

本轮把大厅与探索/战斗的运行时场景统一为 2D 分层背景。GDD 的第一张地图是「混沌领域」：6×6 三层、外层/中层/核心逐步向中央 Boss 格推进。因此背景采用中央漩涡与悬空遗迹作为视觉动线，不把格子、Boss、泉水或任何动态信息烘焙进图片。

## 运行时资源

- `client/assets/backgrounds/chaos_realm/hall_far.png`：ImageGen 生成的远景层，包含深处遗迹、悬空岩岛、瀑布与中央远景漩涡。
- `client/assets/backgrounds/chaos_realm/hall_mid.png`：ImageGen 生成的中景层，包含近处拱廊、黄铜灯笼、桥面和中央平台。
- `client/ui/layered_backdrop.gd`：Godot 2D 合成节点，负责全屏铺放、轻微视差、探索场景色调以及近景程序化石柱/岩体/符文/灵能雾。

大厅与探索/战斗都使用这套分层节点；战斗 UI、怪物、角色和卡牌仍由原有 2D 控件绘制。图鉴页切换为既有图鉴底图，避免卡牌阅读区域被场景细节干扰。

旧 `camp_hall.png`、`dungeon_battle.png` 以及 GLB/Blender 文件不再被运行时背景选择使用，仍保留在工作区作为历史/可编辑归档，不进入本轮客户端视觉路径。

## ImageGen 提示词摘要

使用内置 ImageGen 生成，未加入文字、Logo、角色或 UI：

1. 远景：深青色地下圣殿、远处拱门与青色晶体、中央小型漩涡、UI 安全留白。
2. 中景：近处石拱廊、悬挂黄铜灯、桥面与中央圆形平台，边缘构图、中央保持清爽。

透明近景素材的后续生成请求受到 ImageGen 服务 401/IP 未授权限制，因此近景采用 Godot 2D 程序化图形补齐，避免引入新的不透明背景板。
