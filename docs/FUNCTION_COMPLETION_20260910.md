# 2026-09-10 功能补全与本地验收

本轮按背包与遗物、卡牌升级、战斗信息、装备对比、登录与平台、分支验收的顺序补全。
规则依据为 GDD v0.67，客户端继续采用已选定的 Godot 4.7.2。
统一配置版本为 `gdd-0.67-gameplay-completion-1`。

## 已实现

1. 局内显示完整 20/28/36 格背包与真实安全格；支持拖动/点击换位、穿脱五防具、
   本命武器锁定展示。战斗和读条期间禁止整理。三选一可直接穿戴，旧装退包；
   包满时明确选择替换物并回收。遗物替换物则返回原堆。
   取得、携带、穿戴、回收与死亡资产归属一并落库。
2. 卡牌 +1 至 +5 使用服务端魂材料/额外同名卡报价，保护已保存编组所需副本。
   单张升级副本与其他 +0 副本的等级随准备、开房、洗牌、PVP 冻结和恢复保留。
   品质保持不变；升级确认展示当前/下级效果与准确费用。
3. 出牌预览在克隆房间中调用真实出牌逻辑，不改变原房间牌堆、随机状态、生命、
   奖励或版本。显示核元素、各类型伤害、实际治疗/护盾、控场、耗血与抽牌变化。
   每组伤害同色合并；攻击/受击仅闪烁缩放。过期预览和旧战斗回放不播放成当前反馈。
4. 本命状态、套装激活件数/贡献、抽牌间隔、对手职业/名称及当前逃脱率由服务器提供。
   地图只公开 Boss/源泉/自己；对手手牌、机器人身份和异格状态不公开。
5. 奖励、仓库、市场提供完整装备，支持同部位对比。防具与专武强化显示服务端报价、
   可用材料和当前/下级收益；确认时重新取报价，写入仍校验版本及余额。
6. 登录先核对服务能力和配置版本。401/会话顶替清除可操作状态，显式重新登录恢复。
   Steam 票据适配、缺插件/AppID提示、调试构建本地登录、Windows 导出预检已经接入。
7. 补齐预览依赖的既定规则：职业显、紫燃料顺序、向反治疗、第三元素不加相克对、
   R+1 不叠、潮汐逆、湮核独立双元素、同目标眩晕递减、PVE 阻断转定时双倍充能、
   耗血后计算载岳、出牌先释放手牌槽，以及击杀怪物卡进入本局弃牌。
8. 外层游荡宝箱按 0/1/2/3 只与 40/35/20/5 权重生成，位置与六种元素状态保存。
   匣灵替代本格小怪、每人独立；奖励只将装备升一档，封顶橙。实例卡沿用同一美术 ID，
   实例元素随 PVP 和重启保留。非宝箱出生格使用 O1-O5；中层邻核心的 8 格使用
   E1-E6，四角 4 格使用 M1-M5，既有地图布局和宝箱随机流不变。
