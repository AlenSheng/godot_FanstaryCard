## 1. 状态与统计口径

- **已有**：工作区已有对应资源，允许进入复用和验收环节；不表示所有使用位置都已完成视觉验收。
- **通用图代用**：目前仅有按部位或类别区分的图标，尚未覆盖具体装备外观。
- **待补图**：当前资源中未发现满足该需求的独立图片。
- **待接入**：图像来源可复用，但目标界面仍缺图片展示或统一映射。
- **运行时绘制**：仅用于动态文字、数字、填充值、倒计时和数据驱动颜色；凡列入 8.5 的状态底、边框、图标、遮罩和反馈装饰均须使用正式美术素材，纯代码色块只作临时兜底。
- **待验收**：须检查最终画面、交互和缩放；历史预览不自动批准当前版本。
- **预留**：记录未来范围，当前版本不开放对应玩法或投放。
- **待归档**：曾交付但源文件当前不在工作区，需要恢复原件。

## 2. 全局美术规范

- [ ] **STYLE-01｜整体风格**：沿用现有卡通奇幻手绘风，形体清楚、边缘可读；统一面板材质、描边、光源和物品视角。
- [ ] **STYLE-02｜配色**：以现有深青 `#172d35`、暖纸色 `#efe3c7`、低饱和黄铜 `#d3ae68` 为基础，参考现有装备的深蓝金属、皮革、金属包边和左上高光。
- [ ] **STYLE-03｜品质与元素分开**：品质表达在品质框和材质档次；元素表达在局部宝石、纹样和属性标记。不能把金元素等同于橙品质，也不能把木元素等同于绿品质。
- [ ] **STYLE-04｜元素色**：火赤橙、木翠绿、水青、金浅金、土褐、直伤白；卡面、意图、预览和飘字保持一致。
- [ ] **STYLE-05｜专武色**：牧师青、法师赤橙、盾卫褐金，独立于白绿蓝紫橙红品质体系。
- [ ] **STYLE-06｜独立主体**：道具/装备只画物体本身；名称、品质字、价格、数量、强化等级、按钮和边框分层制作。
- [ ] **STYLE-07｜透明度**：最终独立物品为真实透明 PNG，检查深色主体、孔洞、细柄和边缘；不能留下棋盘格、黑矩形或抠图色边。
- [ ] **STYLE-08｜清晰度**：装备/道具建议以 1024×1024 制作、512×512 导入，并验证 64/96/128 像素显示。此尺寸为本清单建议，已有合格尺寸可保留。
- [ ] **STYLE-09｜小标记与状态**：图标建议 128×128 或 256×256，文字和数字保持运行时绘制；可用已有图形叠层表达状态。

### 2.1 分辨率与包体预算

以下尺寸均指**随游戏发布的运行时图片**。美术母版可按 2× 或 4× 制作，但母版、PSD 和生成中间图只归档，不放入 `client/assets/imported/`。

- 小图标/角标：建议 64×64；实际显示不超过 48×48 时可降为 48×48。单张目标 8–30 KiB。
- 道具/货币图标：建议 96×96；详情大图确需放大时最高 128×128。单张目标 15–50 KiB。
- 装备格、背包格和状态覆盖层：建议 128×128；透明区域裁到主体安全边外 4–8 px，不保留大面积空画布。
- 按钮、输入框和列表行：按钮建议 256×64，输入框 320×64，列表行 384×96；全部采用九宫格，避免为不同长度重复出图。
- 中小面板：建议 384×192 或 512×256；九宫格边距建议 24–32 px。目标 40–150 KiB。
- Tooltip/提示条：建议 256×128；标题横幅建议 768×160；只画边框和装饰，中心内容区保持干净。
- 卡牌覆盖层：运行时建议 218×376；若边缘细节在 1× 下不清楚，允许 436×752，但不得同时打包 1× 和 2× 两套。
- 地图格/目标圈/行动卡覆盖层：建议 192×192 或 256×256，按实际控件尺寸选择最小档。
- 全屏转场：不新增 1920×1080 透明 PNG；拆为 768×160 标题条、960×256 装饰带和运行时纯色遮罩。
- 仅不透明场景背景允许 1920×1080；优先 JPG/WebP，质量 82–88，单张目标 250–700 KiB。含透明边缘的 UI 保持无损压缩。
- 状态变体优先用“一张基础底 + 小型美术覆盖层/遮罩”；禁止复制整张大面板只改颜色。循环动画使用图集，例如 8 帧 × 64×64 合为 512×64。
- 固定像素尺寸的 2D UI 默认关闭 mipmap；仅确实跨越多档缩放的图片启用。导入后检查 `.ctex` 和发布包体积，不以源 PNG 大小代替最终包体结论。

包体控制目标：本轮 5 项邮件素材与 14 组状态素材新增总量优先控制在 **8 MiB 以内**；若超过，先检查大面积透明画布、重复状态底、误打包母版和全屏透明图。
- [ ] **STYLE-10｜面板**：能伸缩的面板、按钮、槽位记录九宫格边界；同类状态保持相同尺寸和点击区域。
- [ ] **STYLE-11｜效果图**：需要交付效果图时，每个 GDD 模块独立 1920×1080；关键阅读区左右留 80px、上下留 48px。整屏效果图用于评审，不作为烘焙数值的运行时背景。
- [ ] **STYLE-12｜卡牌规格**：外框基准 218×376；图鉴插画按 2:3，原始推荐 768×1152、下限 512×768。普通、职业、怪物卡外轮廓统一。
- [ ] **STYLE-13｜选中可读性**：选中、灰显、焦点和锁定状态仍能辨认品质、元素和物品轮廓。
- [ ] **STYLE-14｜战斗表现**：沿用贴图闪烁与轻微缩放、分类型飘字和目标描边，不新增骨骼攻击、弹道、刀光或全屏技能演出资源。

风格依据可直接查看 `client/assets/imported/UI/Item/`、`UI/CardCodex/`、`UI/Characters/`；已有素材联系图位于 `outputs/ui-complete-20260910/style-reference.png`，它只是现有图片的排版核对图。
