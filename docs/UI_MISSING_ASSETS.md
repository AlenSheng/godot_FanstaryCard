## 生成与导入约定

- 本清单按独立组件审核，整屏效果图只作为布局与风格参考，不作为可交互UI背景。

- 200张图鉴插画已齐全；212条cards绑定包括12张怪物图复用，并非212张图鉴插画。

- 怪物卡与战场同一物种使用相同造型，暗红框与红装品质框是两种概念。

- 角色、商品、装备、价格、容量、日限、生命、伤害、费用、冷却和玩家名均由真实数据驱动。

- 纯面板、按钮、空槽、血条、线段、字徽和状态变化优先复用9切或Godot绘制，不要求额外imageGen。

- 场景由Blender生成；不要把场景条目复制到imageGen任务中。

- 每次生成单个文件，文件名按条目交付；不要拼成带文字的素材总览或整屏UI。先参考相应效果图的布局和色调，再参考列出的现有主体图。
- 全身主体 PNG 使用真实透明背景，四周保留约 8% 安全边。Alpha 0 只能用于背景，不能把深色甲片、翅膜、关节或眼睛抠除。
- 普通/职业卡按 218:376 外框比例；插画窗口按 2:3，原图鉴插画为 768×1152。怪物牌从同物种战场图裁切即可，不要重新发明另一种造型。
- 所有本单待补组件都是独立主体/固定比例边框，默认不做九宫格。通用可伸缩面板/按钮已存在；9切边距从已有 sprite_manifest 导入，不能把人物、文字或图标拉伸。
- 效果图中的具体伤害、属性、费用、生命、背包容量、价格、日限和时间只用于版式辨识，最终值由服务器和配置提供。

## PSD 核验结果

通过 psd-tools 只读检查了 15 个 PSD。它们都有图层，但多数图层只是抹字后的整块截图；隐藏文字层不等于获得了可随数据改变的空白组件。

- 所有15个PSD均有图层；存在type文字层不代表像素层无文字/内容污染。

- 大量图层名为无字完整底图，实际上仍保留固定角色、装备、网格、图标与抹字灰块。

- map的地图标记层与地图格层均为带首领/泉水/自己位置的固定整张地图。

- shop的商品像素层整块模糊，无法恢复独立商品插画。

- gear角色像素层是带背景和相邻装备槽的矩形裁片。

- action PSD较可用：空标题、空面板、普通/选中空行动卡、独立图标、干净地牢背景可分别提取；图标alpha需复核。


证据：[PSD 图层清单](../outputs/audit_psd.json)、[行动层 1](../outputs/audit_psd_layers_1.jpg)、[行动/奖励层 2](../outputs/audit_psd_layers_2.jpg)、[地图/提示层 3](../outputs/audit_psd_layers_3.jpg)、[商店/装备层 4](../outputs/audit_psd_layers_4.jpg)。
