# P2 素材替换与功能验证

2026-09-09：本轮收到的 16 张 PNG 全部登记，15 项已接入界面，冰霜幽灵清洁图保留为身份待定素材。当前 416 张位图、212 张卡图和 12 个怪物物种映射完整，原 27 项请求的 28 个 PNG 全部存在，没有新增必补图片。

## 已实现

- 火蝠、锈刃鼠、石甲卫的战场与怪物卡同步使用透明修复图，原图及来源信息保留。
- 牧师、盾卫在大厅、准备、装备与战斗使用统一立绘；准备和战斗根据已锁定职业显示，不被大厅选择覆盖。
- 三职业本命徽记接入大厅与 PVE/PVP 的己方本命区，显示名称和静态能力说明。缺少权威快照的实时连携/加成数字继续等待接口支持。
- 商店按真实 `kind` 和 `payload` 选图：卡包、碎片包、高级/顶级背包使用专用图片，三职业魂使用对应图标，每日单卡显示具体卡名与插画。每份数量、价格、日限和确认文案跟随商品数据。
- 商店原有白边/细长商品卡底替换为干净通用面板；商品横向滚动保留，首尾商品均可访问。
- 高级/顶级背包图片复用于准备页，容量与安全格文字不再裁切，显示实际持有量。无库存档位不可选，失效选择退回免费包，锁定准备继续显示冻结档位。
- 商店读取并刷新背包库存，高级和顶级合计最多持有 3 个；库存未同步或已满时禁用对应购买，提供刷新入口。最终购买校验仍在服务器。
- 泉水、遗物堆、撤离门替换行动图，地图源泉使用同一图标；图片忽略鼠标输入，保留原有行动权限与操作。遗物详情接口未齐，拾取按钮继续禁用。

## 验证

- 导入器 7 项回归测试通过，包含清洁图优先、原图回退、恢复后来源保留、不完整输入拒绝与重复导入不改字节。
- Godot 6 项测试通过，包含全部资源映射、P2 取图、Protobuf、状态约束与界面/预览脚本编译。
- 原生预览 66 张，覆盖 1920×1080 与 1280×720，布局断言无错误；重点人工检查三只修复怪物、12 物种卡面、角色、本命、商店首尾、背包容量、行动和地图。
- 预览交互断言覆盖：房间职业优先、锁定准备立绘、背包可用/不可用/库存已满状态、每日单卡图片与确认文案、图片不挡鼠标、地图切换与遗物保持禁用。
- Docker 联网测试 18 项通过，约 241 秒；实际发生 18 次连放、2 次目标切换、2 次领奖、2 次移动、一次泉水回复、断线恢复及死亡结算回城。真实商店的每日单卡名称、数量、价格与库存读取已显示正确。
- 本轮未执行真实金币购买；购买确认及背包可购买状态使用离线数据验证，服务器现有交易规则未修改。联网过程仍记录 20 次命令拒绝、共 41 条通知，主要涉及房间版本冲突、状态改变与结算后房间失效；此次资源接入没有解决这些既有并发问题。

联网视口录制 334 帧，2 fps 视频位于 `client/evidence/live/gameplay.mp4`，抽样帧复核见 `outputs/p2_live_review.jpg`。最新报告位于 `client/evidence/art/report.json`、`client/evidence/live/report.json`；截图目录保留历史文件，以报告计数为准。
