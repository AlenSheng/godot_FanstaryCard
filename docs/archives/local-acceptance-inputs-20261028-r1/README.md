# 本地验收工作区历史输入

保存本轮核查发现的 30 个不同工作区内容版本、其关联 UID，以及 92ebc206 的三份三机测试控制源码。manifest.json 记录原工作区或 Git 提交、原路径、字节数与 SHA256；原件未改写。

这些是历史复现材料，不是当前生效的客户端或自动测试入口：旧 UI 早于最终布局和字体验收；旧状态恢复与回归脚本已由 release 的较新实现取代。run_*_private 与 notice 夹具是特定阶段的注入输入，依赖当时的工作区和输出环境，不注册进当前回归队列。

三机 100 人批次的来源、测试机客户端供给限制与 CPU 调整记录继续保留。其控制代码放在文档归档内，不恢复已结束的队列，不改变容量结论，不把测试机限制解释为服务器无法承载 100 人。

恢复复现时须先选择对应版本及私有输出路径；此归档本身不授予任何历史批次或来源缺口通过。其他分支与工作区均未重置、删除或合并。
