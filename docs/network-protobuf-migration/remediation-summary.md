## 性能证据

- 同一真实 Bootstrap、同一进程交错各 20 次：Godot 解码均值 **76.574→17.720 ms（4.32 倍）**，每次输出字典完全相等。
- 保留单份输出的 Godot 跟踪内存增量 **2,570,112→1,441,116 字节**；这是保留内存观察，不是累计分配量。释放后净增均 404 字节。
- 服务端同样本三轮独立 Release 交替测量：PB 编码分配 **779,469→286,757 B/次（减少 63.2%）**，耗时 **3.91–4.55→2.32–2.85 ms/次**；JSON 对照 1.33–1.67 ms/次，不能声称 PB 全面更快。
- 并发执行集成测试期间的耗时不用于性能结论。
