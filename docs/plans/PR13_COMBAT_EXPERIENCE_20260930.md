## 1. 两条执行轨道与冻结边界

**轨道一：正确性、可解释性、测量和操作反馈。** 可先修：数值测试与当前 API 对齐，选牌顺序和预览一致性，等待原因，命令去重与迟到回调隔离，战斗进度指标，脚本策略偏差，长尾样本归因。不得为修 UI 改战斗公式。

**轨道二：隔离数值候选。** 复用已有策略，在固定种子、固定规则版本的实验环境比较；正式默认仍保持当前规则。将条目纳入队列只授权设计、测量及后续受控实施规划，不等于启用候选或新的生产压测授权。没有证据的候选可由 MAIN 记录 `NoChangeWithEvidence`。

保持 GDD v0.70 的首张合格单元素牌定核、线性共振、向反与逐卡 floor，不恢复旧多数元素/非线性算法。保持三职业生命 70/80/100、各职业既有护盾上限、自然抽牌地板、基础20张、手牌5张、开局3张、现行死亡掉落。PVE 阻断转加速与自然抽牌间隔地板是不同阶段，不能因最终间隔更短就当作穿帽漏洞直接删除。

不自动启用本命、怪物池、背包或机器人相关候选；不调整币价、掉落、红装、厄运或钻石。不得用自动弃战、放宽超时、提高停止线、缩短战斗负载或调低怪物难度替代原容量验收。
