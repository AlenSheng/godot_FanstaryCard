# PR13 原 T03 完整 360 批最终核验准备

最终云端元数据核验要求原 360 唯一单元、2,880,000 真实见证、三个完整原种子块、每原分层每臂每块 1,000 样本、四条件各 720,000 见证。逐单元确认原生正常退出、无 OOM、来源不变、原独立状态／预览／实例消耗／上限守恒验证、4,000 个原配对与单质量变化核对、G 全量成员 SHA／归档 CRC 保管及精确清理记录。原完整源与当前服务端／协议字节一致。

最后 B2 和原全 360 批本地核验只执行字节、哈希、CRC 和 JSON 身份检查；实际原生规则判据在腾讯云。总核验等待原控制器 final，不以部分块、复用摘要或其他小样本代替原分母。原 720,000 场代表性实验和 314 个统计缺口继续保留，加性边界数据不得改写历史原件或伪称自然对局／容量通过。

在当时实际完成 310 批的云端对照，总核验被原控制器拒绝，最终通过文件未创建。对照和工具原件已 G 盘 SHA／CRC 校验。本阶段仅交付最终核验工具和真实不足分母对照，不补齐规范 EXPERIMENT、自然对局或 MAIN。
