原客户端、当前保护运行镜像、实际配置和默认Guardian卡组保持；角色通过原class选择流程，策略仍baseline_all_hand。不削弱卡组或改变怪物、路线、装备来加快完成。每局保留实际有效动作、自然死亡／撤离和正常ACK，资产／路由完整复核，放弃、截止和drain ACK不计自然局。

指标只属于已核验当前运行进程，采样与三窗口STOP、CPU／磁盘／actor门、500MB底线保持。全部原JSONL和终态留G。本S0只准备独立输入和执行器，未启动新玩法或授予验收；待其他客户端正常收尾后按唯一真实客户端执行，容量和真人决定不变。
