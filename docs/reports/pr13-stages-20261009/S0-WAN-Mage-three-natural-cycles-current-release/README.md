# 本地真实法师客户端到当前云端运行镜像

冻结当前release原客户端、Game存储、Gateway与原始gameplay_load_client；只生成隔离Godot项目和独立用户目录。经公网严格HTTPS/WSS访问自有云服务，使用正常登录及默认法师卡组，未预置资产、路线或内部状态。

一账户三局，原600秒整体观察预算及120秒清理预算。每局必须观察到实际战斗胜利、自然撤离和服务器ACK，资产及路由核对完整；原脚本的截止撤离、放弃、错误及清理ACK均保留而不计为自然完成。该基线不替代其余职业、十人、多场景或故障LIVE合同。

全部客户端输入、原JSONL、引擎日志与结果保存在G盘；本地仅真实客户端模拟及字节/SHA/CRC/JSON元数据核对。云端仍保留当前临时测试限额及北美延迟门槛，容量延期和真人排除决定不变。实际运行前后检查云端镜像和资产状态；S0没有执行新LIVE游戏或授予验收。
