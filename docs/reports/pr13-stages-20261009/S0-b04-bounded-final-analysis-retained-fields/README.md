# PR13 B04 最终统计保留字段内存边界

R2仅保留最终统计实际读取的22个原字段，原始完整行、诊断原件和R1分析工具保持原样。撤销这项存储修改后，AST与原R1完全一致：全分母、重复／错层拒绝、三块每臂3,000种子、量化规则、配对seed cluster重抽样、1,000次bootstrap及固定seed均未改变。

腾讯云使用实际三职业BOSS资源校准原件120行，逐职业九指标共27个配对统计结果一致；观测时间分位与胜率Wilson区间一致。实际120行的递归保留Python内存由688,706降至148,000字节；这是该对照范围内的测量，未保证完整运行峰值。空和不完整原始索引均被5,400批／216,000场分母要求拒绝，没有生成正式最终统计。
