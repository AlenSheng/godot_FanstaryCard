# B04 缩减540批后的RAM输出安排

新目标保留540批、21,600场、原英雄／怪物组／策略／种子块，313批已有完整G盘原件，剩余227批。原研究计划、已完成批次、原失败证据不覆盖。

每批输出改到腾讯云 /dev/shm 的任务专属路径，实际文件系统必须是 tmpfs。输出预算仍为256 MiB，启动时额外为输出预留256 MiB内存；保留500 MB可用内存底线、原1 GiB容器限额及64 MiB启动余量。云盘仍保持15%底线并为元数据保留16 MiB。原编译Domain、验证器、输入、样本和失败门槛逐字节保持不变。终态成功后仍完整传输到G盘并核验SHA、gzip CRC和全部成员，随后清理该批RAM输出。

已核对旧成功导入缓存和无容器使用的旧SDK镜像完整G盘备份后清理。两处实际释放空间仅约各0.1 MiB，不能按逻辑大小宣称已释放大量磁盘；Docker和源码硬链接仍共享底层内容。该RAM安排消除根盘为大输出预留256 MiB的需要，额外内存条件仍必须通过。原540批齐全后再执行云端最终统计及验收。
