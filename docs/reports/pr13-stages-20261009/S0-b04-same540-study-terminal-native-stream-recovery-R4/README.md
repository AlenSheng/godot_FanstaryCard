# B04 同一540批研究原件传输恢复

349批完整G归档不改。下一批云端原生已正常退出、验证器通过、容器移除，完整RAM输出仍在；远端该研究的delivery／stream／cleanup／launch进程实际均不存在。G归档仅1,497,391字节、缺少gzip尾部，无完整G回执，云端未执行cleanup。此为已核实的原件传输中断，不因一次观测超时判断原生终止。

核实终态后停止原本仍存活的本地协调器，保留日志及原截断文件于G的retained-interruptions。新唯一协调器先复验349批SHA／CRC，再传输既有成功原生原件；完整成员及SHA／CRC核验之后才执行该批RAM清理。原生不重跑，540批矩阵、输出预算、运行制品、验证器和停止门槛全部保持。

SSH使用原严格主机／算法／压缩通路，增加5秒保活并为exec确认设置15秒界限。未知动作结果即停止并保留诊断，不自动重发launch或cleanup。传输恢复并完整清理后再接续原研究的下一个未执行批次。该阶段未启动新原生或授予验收。
