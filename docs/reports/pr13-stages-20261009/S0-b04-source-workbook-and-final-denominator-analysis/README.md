# PR13 构筑源表对应与完整分母最终分析开发

腾讯云原生当前 ConfigExporter 从冻结工作簿重新导出 13 表、1,599 行。R2 退出 0，真实退出状态、日志、生成六文件与当前前后端 Git 对应逐字节一致，生成包字节与完整实验实际嵌入资源 SHA 一致。工作簿和编译导出器精确来源保留；不以版本号相同代替字节一致，不把 canonical bundle SHA 当作含哈希字段的原字节 SHA。

R1 包装器误将输出目录参数视作单文件，在原生成功生成后读取目录而失败，其结果不重写。读取已生成六文件独立复核通过，R2 另次只修正目录处理并记录原生退出状态。两次全部可用原件到 G 盘，SHA／CRC 已核对，生产配置未改。

最终分析器强制 5,400 原始分段、216,000 场、36 层、每层每臂三个 1,000 原种子块；所有死亡／未结束样本留在配对分母，以种子聚类 bootstrap 区间比较。全体耗时和条件胜利耗时分别呈现，请求与实际资源、溢出、合法行动／策略主动等待分别报告，不因点击频率提高便宣布更强。空分母与部分分母云端对照均拒绝，不产生最终统计。该分析尚未在全量正式数据上执行，完整案例覆盖、区间评审、渲染和 MAIN 仍独立。

这一步补齐实际源表对应证据和分析工具可执行性，不关闭规范验收层；全构筑队列继续等待原 T03 360 批完成，正式分母保持不变。
