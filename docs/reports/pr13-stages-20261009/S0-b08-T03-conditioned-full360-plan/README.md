# PR13 T03 全量受控边界补测冻结

小样本真实出牌和独立原始状态校验通过后，冻结完整 360 单元、2,880,000 次出牌。原 120 分层、三段种子、每臂每单元 1,000 个样本和四类边界均保留；每单元 8,000 次。固定复用七个经 G 盘哈希核对的试验编译产物，不重复编译产品。业务来源仍为小样本冻结的 release；阶段之间产品文件没有变化。

每个单元使用独占腾讯云进程和容器执行真实 Room.PlayCards，并在云端运行独立原始状态校验。封存原始输出、日志、实际退出状态与来源后，流式传到本地 G 盘。必须先完成所有成员的 SHA 和归档 CRC 校验、成功退出和绑定检查，才能清理对应单元的临时云输出。来源、编译运行时、依赖和失败原件保留。

云端可用内存底线 500,000,000 字节、磁盘余量底线 15%；每单元 256 MiB 输出预算。资源不足则等待，不减少样本或断言。传输观测失败先检查同一个进程，不重新执行原生试验。完整矩阵结束后还需要汇总与正式用例对账，当前关闭 profile 为 0，正式 EXPERIMENT 和 MAIN 均未接受。

本阶段只完成执行计划与输入冻结。原 720,000 场代表性遭遇、314 个边界缺口及 development_first 暂缓项保留。受控出牌补测不代表自然流程、容量或真人体验通过。
