等待完整 360 个逻辑单元、720,000 场的原始 G 盘归档及来源、独立验证和云清理证据全部齐备，才在本地只做字节/哈希/JSON 投影准备，然后传回云端执行冻结的完整分析。本地不执行游戏或统计。腾讯云按 500 MB 内存、15% 根盘预留及独立只读容器执行；统计结果、真实判据缺口和全部原件仍需保存 G 盘后审查。
