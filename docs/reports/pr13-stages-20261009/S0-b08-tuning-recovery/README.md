# B08.3 S0：主核、抵消和回复合同

按当前服务端和 GDD 的 first-eligible、R/P/K/E0 规则冻结验证矩阵。共 13,824 条真实房间边界记录，覆盖 3 个种子、3 个职业、6 个武器等级、4 个生命边界、4 类遭遇、2 个合法装备方案和 8 种出牌顺序。

验证使用当前配置中的合法 20 张牌组及真实持有实例；手牌顺序、生命边界和高生命目标是明确的测试注入。实际服务端预览、出牌、路由和 Protobuf 编解码均纳入核对，客户端读取原始服务端协议数据，逐条比对数值。此矩阵验证合同，不据此声称胜率、真人体验或容量通过。

调节牌详情补充中文和英文说明：能作为第一张定核、计入同核，不增加相克牌数、不进入向反回复基数；其他相克牌仍可间接降低共振。普通治疗与向反回复分开处理，后者不叠加牧师临渊和武器治疗倍率。

B08.2 仍为 Partial，因此 B08.3 先做开发和证据收集，不越过依赖升级集成验收。执行在腾讯云，完成的数据优先归档 G 盘，校验后清理已通过的云端副本。之前失败记录和延期容量项保留。
