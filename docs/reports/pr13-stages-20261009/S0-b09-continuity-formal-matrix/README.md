# B09.4 正式连续性实验预登记

三职业 × 三个独立种子块 × 每块 1000 配对种子 × 正式规则和 cap3/5/8，完整 36000 条自然路线；36 条开发 smoke 另用 487001 起的种子，不计入正式样本。每条保持相同原生地图、真实战斗、基础 20、观察期、合法可见策略和明确选择成本，全部死亡/撤离/删失结果保留。

新程序使用真实 Protobuf 编解码、RealtimeCommandRouter 和 RoomActor 路由，记录原始请求/回应的实际字节数与计数；这些属于原生进程内协议请求，不声明公网 HTTP/WSS 延迟。关键牌、选择成本、CPU/资源分钟以及原生道具种类/数量和实际保留经济物品分开记录，不臆造跨币种价格。前三个自然选择生成原始服务端快照与协议向量，供当前 Godot 读取和真实 UI 选择成本验收。

主要指标为共同 1800 秒观察期内撤离概率，按 seed 配对聚类；首轮每职业 3000 配对种子，10000 次配对 bootstrap，95% 区间与九个主要比较的 Bonferroni 调整区间均预登记。精度或删失不足保持 Inconclusive；未证明稳定收益不启用候选，不能把不确定性冒充无效应。原生实例守恒、隐藏库序负控制与副作用单列继续要求通过。

此阶段冻结正式输入与待验证代码。云端编译、smoke、完整九单元执行、统计、原始向量的当前 Godot 渲染/请求和选择流程证据仍须补齐；B09.4 与 MAIN 不在此阶段升级通过，正式配置保持原样。
