# 云端静态依赖存储共享

旧源目录中 1558 个静态第三方 DLL 输入路径经 SHA、大小、模式和所有者核对，1534 个重复 inode 合并存储，观察到云根可用空间增加 1,160,998,912 字节。所有原路径、字节、模式和所有者均保留；旧修改时间及 inode 记入云端意图。存在外部硬链接的 inode 只作为保留的共享来源，替换目标须完整识别其全部旧别名。当前绑定组和应用程序集、RAW、日志、结果不纳入操作。

预检发现普通用户不能写部分旧构建目录时，在任何替换之前停止；该无修改失败记录保留。后续在已授权云端目录内完成相同字节共享，失败源和失败证据完整保留，正式服务健康状态 200。此阶段回收空间以供剩余原生队列使用，不升级玩法验收或改写原生结果。
