# 云端证据存储回收

B09 R2/R3 已结束源副本的 1377 组依赖与 Git 副本逐字节相同，2754 个原路径和内容均保留，改为共享存储；旧修改时间在云端意图中记录，失败源、RAW 和日志没有删除。已结束 HTTP 下载缓存的 93 个成员先完整存入 G 盘并校验 SHA 与 gzip CRC，再清理云端副本；另回收 G 盘已有完整通过归档的 E4 单个重复缓存包。

三次操作观察到云根空间共释放 240,762,880 字节。Linux 缓存目录含 Windows 不支持的冒号，本地提取使用显式路径映射，原始归档成员名和内容均未改写。容量准入仍使用原有 15% 云盘安全线与 500 MB 内存安全线，验收状态不因清理升级。
