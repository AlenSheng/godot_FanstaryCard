全量统计排队任务名修正

冻结运行器要求 `pr13-` 加 attempt。旧队列多加了一段 `cap-full-statistics-`，会在原生计算启动前被运行器拒绝。已只读核验云端 projection、startup、dispatch intent 和两个候选 unit 均不存在；核对本机旧队列父子进程身份后结束尚未执行的等待进程，保留旧脚本和输出。新队列继续等待全部 360 个 G 盘归档单元，冻结分析算法和输入要求未改。

依赖归档队列已设置：只在唯一云端统计任务产生结果后保存全部元数据、运行器、分析源码、输入 projection、输出、scratch、systemd 文件和原始 journal。每个成员核验 SHA256，并校验 gzip CRC。失败原件保留，不自动清理云端数据。本检查点没有执行统计，也没有升级 MAIN 或其他验收状态。
