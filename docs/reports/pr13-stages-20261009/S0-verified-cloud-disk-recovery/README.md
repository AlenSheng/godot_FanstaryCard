# PR13 云盘空间恢复与原队列续跑

已通过的双语言 Mage GUI 专属输入经 G 盘 6,840 次逻辑成员复核和两个归档 SHA／CRC 核对后删除。显示分配量约 1.90 GB，但硬链接共用来源仍保留，实际仅释放 1,331,200 字节。成功的默认策略审计独占输入再核对后释放 16,183,296 字节。

云端两个大 Git 包存在完整重复对象。先用原生 verify-pack 核对保留包校验和与对象，再通过 multi-pack-index write／verify／expire／verify 清除 Git 判断完全冗余的包；不手动删除对象文件。全部 19,440 个打包对象 OID 集合、所有 refs、HEAD 和工作区前后一致，失败证据及共享源、SDK、包内容保留。实际释放 1,876,852,736 字节。首个尝试因启动保留量不足在修改前退出，先清理成功独占输入后再执行，资源保护未降低。

内存 500,000,000 字节和云盘 15% 底线保留，Git 完成后云盘可用比例约 18%。原 T03 队列不重复派发，168 批已完成 G 盘核验；下一 Priest-O1-Water-L0-B1 原生 8,000 条见证和独立验证完成，正传回 G 盘。本次观察不提前增加 G 核验计数。原总量仍为 360 批／2,880,000 条见证，既有 720,000 次研究及 314 个缺口不改写。

本阶段只记录空间回收与现有句柄续跑；不关闭新验收层，不签署门禁，不重启已暂缓失败或容量测试。
