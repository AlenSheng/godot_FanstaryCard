# B02 其余数据库验证缺口

原 Domain 已迁移枚举并保留默认值；金标准测试明确限定卡牌、装备、抗性和逐卡取整；策略快照测试覆盖 PVE/PVP、旧字段及拒绝非法值。这些离线通过记录没有完成三项原细则要求的数据库层。

新增九个 PostgreSQL 原生用例将当前房间快照、策略、选牌实例与 Resolver 配置保存并恢复。旧 API 检查使用当前实际 Domain DLL 构建独立旧参数/旧余量探针，保留预期编译诊断，同时确认持久化当前合同不被修改。候选及默认断言独立；限定向量配置也写入测试数据库，避免只重新读取内存输入。

策略恢复检查包含新源/旧房间/回滚新房间、持久化中的 PVP 工作副本、旧 JSON 真正缺字段，以及注入无效枚举/余量后既有权威对象不半恢复。配套运行同一来源的 Domain 回归、Godot 数值场景及协议/预览状态回归。本阶段未声明新检查通过，未变更生产规则。
