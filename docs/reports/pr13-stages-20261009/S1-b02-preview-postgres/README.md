# B02.3 层次缺口定位

原始细则要求 OFFLINE、POSTGRES。当前三条检查已有离线记录，均缺 POSTGRES。现有 Domain 测试验证预览纯函数、有效治疗/盾/抽牌/控制和 revision；客户端测试验证过期回复弃置、选牌顺序及首牌主核。现有 PostgreSQL 测试尚未把这些断言连接到真实快照保存与恢复。

因此新增云端临时数据库检查：三个职业各连续预览十次并比对完整快照/RNG/牌库哈希；以数据库恢复后的权威房间生成正逆选序 Protobuf，再由实际 Godot 解码；提交新快照后注入过期 revision，检查权威与数据库不变，并让客户端收到迟到的原生回复。

本阶段只定位与明确补证方法，未声明新增检查通过，也未将任务签署 Accepted。既有容量和严格多局失败继续暂缓。
