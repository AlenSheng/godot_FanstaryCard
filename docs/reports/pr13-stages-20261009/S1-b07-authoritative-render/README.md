# S1 显示层与权威状态连接

测试场景读取真实原生输出的 JSON 文本，逐份核对 SHA 后投影 HP、盾、武器等级、策略和余量到既有玩家视图。每个可见状态都等待实际绘制，再核对玩家区域中的护盾数字和余量按钮；不把字典值或说明文案当像素显示的证明。默认策略应隐藏候选入口，零盾应清除旧盾数字。

三条 case 分成三个有界作业，同一场景脚本通过场景导出字段选择 case。每个作业所有语言/尺寸/帧率组合都走十二份真实权威变体，保存各状态来源哈希与实际显示；每 case 一张英文窄窗口实际截图，GUI 点击使用正常事件路径。渲染截图与原生完整序列分别存放，保留来源和执行边界。

只新增测试场景、已有权威输出的同内容数据引用，以及渲染执行器的显式有界预算参数；不补建 Lua 绑定、不修改生产玩法或协议。所有缺失/失败必须保留，不能缩减变体或把 RENDER 不适用来换取通过。
