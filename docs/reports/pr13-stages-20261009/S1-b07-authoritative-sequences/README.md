# S1 权威序列和可回放状态

新增独立 .NET 探针引用原生 Domain，不修改生产程序集或候选开关。每个 seed/等级/策略执行真实房间预览、出牌、PVP 生存返回、JSON 保存/恢复和地图移动；注入合法已知手牌与边界状态，在输出中明确属于人工边界 fixture。默认/候选使用相同 seed 和可见状态。

完整原始 JSONL 逐行保存操作结果、独立黄金期望与实际前后状态。纯预览/拒绝操作检查整个房间快照不变，成功操作记录护盾/余量和消费的实例；PVP 使用真实 PlayCards 并经 room JSON 重建后返回，比较冻结的整个战斗快照。合法 MovePlayerAndPair 检查离格时盾与余量同时清零。

原始流按块无损 gzip，保存原始/压缩 SHA 和字节数，所有失败仍输出。少量真实权威客户端投影单独供渲染器使用，避免手写客户端预期代替后端值。首轮编译/边界预检先于预登记三块完整实验；预检不是足量实验通过，也不修改原验收登记。
