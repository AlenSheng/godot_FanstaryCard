# B02.3 持久化预览回归与跨端证据导出

新增六个 PostgreSQL 原生用例：法师、牧师、守护者默认策略和守护者小数余量策略分别从数据库恢复后连续预览十次；另外验证正逆选序的真实 Protobuf 往返和提交主核，以及提交新快照后的过期 revision 拒绝。完整快照、牌库、RNG、数据库内容和余量保持不变，预览与提交的确定性字段一致。临时库、测试取消和来源均显式管理。

新增 Godot 场景直接读取上述原生服务生成的两组 Protobuf 字节，核对顺序/主核、当前预览接受、迟到旧回复不覆盖当前状态，并运行既有协议与预览状态回归。腾讯云六个数据库用例、八项客户端检查全部通过，零跳过；独立数据库及实际测试容器已按完整身份回收。

首轮取消标记编译错误、第二轮测试时钟精度不一致及第三轮客户端只读挂载启动失败均保留。客户端在独立只读目录续测，真实数据库六条通过记录单独保留，不把启动失败改成成功。

新增证据导出工具严格检查六条 TRX、各职业实际哈希/余量、顺序与主核、过期 revision、八条 Godot 观察及清理。仅导出原 B02.3 的三条 OFFLINE/POSTGRES 检查。本轮增加验证能力，未改业务数值、持久化节流或公开协议。来源逐字节核验和清单合并在 S3/S6 汇总。
