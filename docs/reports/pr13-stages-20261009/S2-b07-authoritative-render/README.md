# S2 权威状态回放渲染场景

新增三个原 case 场景和共享脚本。输入数据与已保存的原生 render-vectors.json 字节完全相同，继续保留原始执行来源；显示前逐状态核对原文 SHA。每个矩阵点走十二份默认/候选、六等级状态，第一条展示十次预览/四类拒绝/成功提交/已消费实例重用，第二条展示五次累计和五类上限边界，第三条展示冻结 PVE、真实 PVP 工作副本、JSON 返回与离格。

检查真实玩家区域的护盾文字、零盾旧值清除、候选余量按钮和默认隐藏，以及正常 GUI 点击详情后的权威余量。使用实际 PVP 布局并读取原生对手状态。每个状态等待真实绘制，保存原文哈希、实际显示和页面不改房间状态的观察；尚待云端执行，不宣称通过。

渲染器增加显式有界 deadline/output reservation 参数，默认仍为 180 秒/64 MiB；本轮每 case 600 秒、24 MiB，原内存 500000000 字节、磁盘 15% 安全线保持。输出实际大小也必须落在预留内。没有改生产玩法/协议/数值或 Lua 绑定。
