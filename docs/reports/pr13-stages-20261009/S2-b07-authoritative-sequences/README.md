# S2 原生权威序列探针

新增独立工具 FantasyCard.GuardianProbe，直接引用原生 Domain。五次真实房间出牌的独立黄金盾合计固定为默认 40/40/45/45/50/50、候选 40/42/44/46/48/50，其中牌面盾每次 7，武器额外贡献对应 5/5/10/10/15/15 和 5/7/9/11/13/15。

每个配对 seed/等级记录十次纯预览、非法目标/未来版本/重复实例/缺失实例的拒绝、消费实例再次出牌拒绝；真实出牌的满盾/零盾/精确补满/溢出；JSON room 恢复、真实 PVP 出牌后的 JSON 重建与生存返回，以及实际地图合法离格。全量前后状态按原生 JSON 文本和 SHA 保存，可独立逐条复核，不用哈希或汇总替代原文。边界手牌与 ActionBar 注入明确标记。

每块最多 1000 配对 seed、每 seed 六档×两策略、每行九段场景。所有错误原文保留，退出非零，不取成功子集。流式无损压缩保存原始/压缩 SHA 和字节数，当前块第一 seed 的真实状态另供后续渲染。该工具实现尚待腾讯云编译和预检，不能据此签署 B07.3。
