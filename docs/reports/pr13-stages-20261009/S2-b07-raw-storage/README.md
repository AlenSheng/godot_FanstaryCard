# 有界、无损的云端逐对局证据存储

增加 gzip 原始证据读取与保存：压缩前核验原生摘要中的原始 SHA256，压缩后重新解压核验相同字节和长度，再保留原生摘要并记录压缩文件 SHA256/长度。分析器拒绝损坏、截断、哈希漂移、同时出现两个原始文件和路径越界；解压总量有上界。逐种子配对、结局、计数、冻结参数及统计方法保持原判据。
