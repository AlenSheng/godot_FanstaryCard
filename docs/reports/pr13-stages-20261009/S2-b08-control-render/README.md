# S2 权威房间状态回放与控制文案

三个原 case 场景直接使用 main.tscn，逐房间原始 JSON SHA 核对后映射当前 player/monster/opponent 控制字段。默认 UI 计时仅在权威边界采样时冻结为 0 ms，调用正常更新函数；明确不声称持续计时网络或 LIVE 已重新验收。每组遍历三职业六档武器的 18 份原生向量，显示状态保持原生战斗/目标 ID 和实际 HP/盾/剩余控制。

主界面四类状态现在使用启用语言文案；多状态按两项一行显示并重算字体，过期后隐藏旧值。T03 另做四状态同时存在、部分过期和全部过期的开发检查，单列 fixture_only，不拿它替代权威控制原 case。原始向量与 S5-b08-control-contract/matrix/300001/render-vectors.json 字节完全相同。

本轮无协议、窗口算法、Domain 或玩法数值变化。Lua 绑定没有改动；原生与实际绘制的来源分别保存，云端执行前不改验收状态。
