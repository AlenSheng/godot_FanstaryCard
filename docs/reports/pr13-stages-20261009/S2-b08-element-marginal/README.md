# S2 原生单卡配对入口与控制统计

新增 --element-marginals 独立入口，复用实际遭遇 Simulate。先验证共同基线二十张牌，再分别构造仅一张 Green 调节替换的卡组，通过现有 PairedDeckBudget 与 DeckRules 验证。配置表、构筑、同品质/成本预算、当前规则、seed 块、策略和观察期写入原生 manifest；输出 gzip JSONL，压缩/原文 SHA 和 512 MiB 原始界限保留。

新统计分牌面请求、职业换算和递减后控制。实际观察的控制按每个活目标的剩余计时与下一真实 tick 的交集累计，不重复加同目标重叠；按目标分账，额外记录新增可用控制与死亡/窗口截断区别。治疗、盾的请求与实际/溢出并列；即时请求与提交后实际手牌到达量分列，后者明确包含蓄能转抽，不能拿两者差额冒充即时抽牌帽损。

当前 Domain/玩法/协议没有改动，既有实验入口保持原行为；新统计只在新入口启用。尚待云端编译与真实预检，完整配对实验、边界、RENDER 和最终验收尚未完成，登记表保持原状态。
