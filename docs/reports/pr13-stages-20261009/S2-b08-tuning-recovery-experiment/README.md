# B08.3 正式实验实现入口

增加独立 `--tuning-recovery-experiment` 入口，按 S0 冻结的合法 20 张牌组，只替换一张同品质、同稀有度、同解锁成本的 Green 水调节牌。三个职业、四类实际遭遇、三个替换方案、三个互不重叠的千种子组共 216,000 条遭遇记录、108,000 对。

复用当前真实房间与可见手牌 basic 策略。新增记录回调默认关闭，既有实验入口的出牌、计时和规则行为保持原路径。逐次真实出牌保存持有实例、职业、当前生命、装备、时间、独立公式、实际 Resolver 草案及真实提交结果。原始事件分段 gzip 保存，128 MiB 原文分段、每执行单元 2 GiB 原文硬界限；总云端临时输出仍受 512 MiB 上限监控。预算不足时保留原始文件并停止，不能删事件换取通过。

独立公式核对 first-eligible、R/P/B/K/D/E0、逐牌取整及普通治疗/向反回复两条路径。实际条件发生数与未发生数分列，另记录错误套用牧师倍率的反例。数据核验器逐事件对账到遭遇动作数和治疗请求、有效值、溢出，校验两臂输入、原始字节哈希、压缩哈希和 CRC。

当前为实现入口，云端编译、小批预检和完整正式实验尚待执行。本次没有改变生产数值或激活候选；不能依据该入口或短样本升级验收。长对局只按实际结束、死亡、删失或错误记录，不因盾卫打得久而自动判错或削弱。
