# S2 云端画面验证运行能力

新增隔离的 X11/Mesa 软件渲染镜像和有界运行工具。构建基于已冻结的原生测试镜像；实际画面运行禁用网络，源码只读挂载，用户数据独立，输出保存到本阶段目录。按预登记的 500,000,000 字节可用内存线与 15% 磁盘线采样，测试最多 180 秒、1 个 CPU 核、1.5 GiB 内存。

容器启动后、回收前均校验完整容器 ID 和所属标签；来源路径越界或字节变化、错误资源归属、内存或磁盘不足均阻止继续运行。源码修改前后 hash 与原始资源采样、退出码、图像和日志留存。四项原生单元检查覆盖这些拒绝边界。

新画面夹具使用实际项目场景和既有客户端状态入口，覆盖两种语言、三种分辨率、八种等待/出牌场景，共 48 行，保存 8 张英文窄屏图像。显式使用窗口模式，同时检查实际窗口与 Image 像素尺寸，避免把缩放后的 ViewportTexture 尺寸当成截图尺寸。

腾讯云实际 X11/llvmpipe 执行完成，完整结果在 S3 报告。此能力用于功能画面验证；硬件帧率、真实网络多人、自然多局、容量与真人体验均需各自证据。没有升级原 132 项验收状态。

回滚：独立回退运行工具、镜像定义和画面夹具，保留原始阶段证据及镜像 ID；只按明确身份处理本阶段资源，不使用全局清理。
