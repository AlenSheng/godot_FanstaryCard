# S2 战斗等待反馈实现

基于 S1 腾讯云修前对照，客户端先识别“手动切换目标等待确认”，再识别待确认出牌或已有重试队列。目标死亡后的自动同步和不相关只读请求仍按当前手牌、控制状态和已有出牌权限报告等待原因与可操作机会。

增加中英文目标确认文案，直接由现有战斗界面的等待提示使用。补入客户端回归入口：冻结的 15 条状态检查及 8 条实际 UI 组件文案检查。组件文案检查属于原生 OFFLINE 层，不能当作渲染帧证据。

修改范围仅为客户端反馈、文案和测试；目标选择、出牌权限、服务端数值与协议合同不变。没有开启数值候选、玩家压测或临时公网测试入口。

审查结论：目标确认复用现有有效意图判定，目标死亡的同步仍采用当前存活目标；预览读请求不进入业务等待分类。状态查询不修改手牌、生命、目标或资产。缺少真实运行层的原验收状态继续保留。

验证在 S3 云端执行，执行源文件以 Git 字节和 hash 固定。回滚为独立提交回退原因分类及文案，保留 S1 修前记录和 S3 结果。
