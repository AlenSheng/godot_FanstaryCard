# S2 目标按钮与预览布局修复

基于 S1 的 24 次真实 GUI 点击被 CombatPreview 截住的复现，将多目标按钮从 y=512 上移至 y=472，保留 50 像素高度。按钮下边缘为 y=522，与原 y=528 的预览面板留出 6 像素间隔。

同步缩短多目标图片区域并上移行动提示，缺图占位区域一并收紧，避免新按钮位置与上述内容挤占。无多目标选择按钮时保持原布局。目标选择命令、确认过程、选牌列表、GDD 死亡后选择存活目标和数值配置不变。

云端完整验证通过：48 行正常 GUI 指针交互、48 行等待画面回归、21 组客户端回归。检查使用真实项目场景与正常 GUI 输入路由，并保留实际控件边界、命中控件、目标命令、截图和源码 hash；完整证据在 S3 汇总。

本阶段修改仅为 client/ui/exploration_view.gd 的布局。回滚可独立回退该修改，修前及修后原始证据保留。严格多人、多局与容量测试继续按用户决定暂缓，没有升级原 132 项全量验收。
