# B08.4 帽内有效值、适用性和阶段说明

云端复现了两种说明错误：法师不适用的载壁减伤记成 49% 超限，未激活套装记成 7% 超限。现将不适用、未激活和真正的上限溢出分别记录、显示；抽牌说明区分装备/临时加速限幅与 PVE 阻断转换在限幅之后减半。现行战斗数值和候选默认状态不变。

当前源下 56 项原生回归通过，0 跳过。864 条合法装备和真实战斗状态见证由 Godot 按原始记录逐条核对：270 条五元素抗性与边际值、108 条抽牌推进/阻断/到期阶段、486 条职业适用性及护盾请求/有效/溢出。中英文字内容也核对。首次启动入口未初始化 Game；改为初始化后调用，并重新关联已核验的资源缓存。初次来源核验包含了会被编译改动的 bin/obj，失败记录保留；新批次使用纯源码快照并确认前后哈希不变。
