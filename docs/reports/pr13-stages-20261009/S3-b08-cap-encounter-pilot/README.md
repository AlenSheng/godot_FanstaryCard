# B08.4 实际对局实验工具与预检

当前合法卡组包含 C17 护盾、C20/C27 阻断和实际加速来源；五部位紫装与只升级头部为橙装分别进入真实 BattleRoom。三职业、四怪组、五元素和 0/5 两等级共 120 组、720 场预检完成。33606 次真实出牌和 583820 个时钟步进由独立计算核对，480 个破坏数据对照全部拒绝；56 项领域回归通过且没有跳过。

T01 从合法装备贡献重算 60% 抗性帽及有效边际；T02 独立积分装备/卡牌夹取和 PVE 后置转换，并核对满手蓄能清零、时效结束及真实抽牌；T03 从原始选牌顺序和卡牌护盾基数核对请求、实际、溢出和默认候选策略。升级一件装备会同时改变其他属性，不把结果差异误称为单独抗性或抽牌的效果。

预检的 720 场都是胜利。这是冻结小样本的结果，不能推断整体胜率；316 条未触发的具体场景分母保留在 pilot-coverage.json，不能冒充适用场景已通过。完整 360 批、720000 场实验正在推进；三块各 1000 个配对种子完成后另做场景覆盖和完整证据汇总。

第一次静态分析编译失败和第二次枚举序列化校验失败原样保留。第三次只修复独立校验器，复用已通过的编译；其旧卡组不含全部必要来源，因此重新冻结输入并执行第四次预检。没有改生产战斗、配置、协议或客户端。

云端压缩副本曾因临时内存盘不足失败，失败副本保留。随后改为直接流式传到 G 盘，1732 个归档成员及 241 组原始 gzip 数据的 CRC、原始 SHA 和计数完整核验后，才清理通过的输出。结束任务的两份静态依赖缓存也先在 G 盘恢复并逐文件核验，共 4136 个源输入与云端哈希相同，随后只删除缓存，保留失败原始结果、日志和源代码。当前仍使用的运行库和输入保持原样。

原 864 条 OFFLINE 证据在前阶段报告，完整 RENDER 因 900 秒执行预算暂缓。任务仍未整体验收，S4、完整实验及依赖验收待补；此前严格网络与容量失败继续按用户决定暂缓。
