# PR13 B08.3 当前已发布卡牌真实房间合同见证

腾讯云使用当前发布的 ET-FIRE-W、C01、C06、C15，生成三个职业、武器 +0～+5、相同五件紫装有／无 Vitality 两种合法配置、三个原用例，共 108 个真实房间出牌见证。固定初始自身 HP 为当前最大 HP 的一半，怪物、卡牌及装备数值均不改写。

调节牌首张可定火主核并计入 R；同核调节与反牌的 P/K、抵消后的共鸣及向反回复基数分别核对；普通治疗保留小数输入后按现行职业／武器／回复加成顺序取整，向反回复只套用当前回复加成。独立 Decimal 判据覆盖所有 108 行，并核对原始前后状态 SHA、二十张原实例、单次扣牌、策略不变及相同顺序输入的预览与实际出牌一致。

R1 的测试判据错误地在职业计算前舍入 6×1.25，原失败输入、编译产物和日志完整保留。R2 修正该判据，逐个成功房间立即写入原始见证，实际退出 0、无内存不足、共享来源与依赖前后不变、精确所属容器已移除。全部 1,688 个成员在 G 盘逐文件核对；其中 1,550 个共同来源和依赖引用已重新核对，不能把旧父批次失败当作本批通过。

本阶段是三项合同的当前真实房间与画面投影准备，不替代原 EXPERIMENT 预算，也未执行 RENDER 全矩阵。当前登记、正式缺口与 MAIN 裁决均保留。客户端后续从原始见证投影取得权威状态，继续核对预览、协议顺序和实际画面。
