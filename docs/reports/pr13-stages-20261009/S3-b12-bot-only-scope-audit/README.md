# PR13 机器人证据与本轮真人范围的实际审计

腾讯云执行精确当前 pr13_review_policy／pr13_public_evidence。先对实际 162 行渲染原件核对公开清单字节与哈希，确保真人判断返回 false 的原因来自机器人类型，而不是缺失／无效原件。六机器人身份、三周期 ID 和机器层完成标记均是明确的分类控制输入，不冒充本次实际参与者或自然对局。

保留真人要求时分类 Partial；本轮按用户范围移出真人后，只有控制的完整机器层能进入 ReadyForAcceptance，而控制的缺层仍 Partial、失败仍 Failed，human_complete 始终 false。仅审计这一分类与范围边界，未授予任何真人通过、实际完整机器层、自然对局或 MAIN 验收。

七个真实输入／输出原件已到 G 盘并核对 SHA／归档 CRC。另记录已通过守护者渲染独占副本精确清理，3,377 文件经完整 G 再核对、终结句柄与无活跃重叠挂载证明后删除；硬链接仅实际回收 450,560 字节，原生输出、原件和共享输入保留。
