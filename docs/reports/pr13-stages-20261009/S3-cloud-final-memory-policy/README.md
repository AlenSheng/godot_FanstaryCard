# S3 最终云端内存与并发政策

按用户授权，此次真实云端测试的本机发压器及腾讯云可用内存最低线为 500,000,000 字节（500 MB），每次启动额外预留 64 MiB。旧测试与默认配置不回写。专属测试实例关闭 IP／实时命令／应用连接池配额，物理 PostgreSQL 连接预算提高到 256，启动后实测生效值。生产配置保持原策略。

腾讯云回归 68/68 通过，包含 500 MB 精确边界、低于边界、监测缺失、旧默认线、协调器使用实际新阈值、错误身份拒绝与数据库覆盖授权。首次检出缺少客户端输入、内存监测依赖和原离线 fixture 没有提供监测值的失败记录保留。补齐精确客户端／协议输入和隔离 psutil 依赖；有效 fixture 显式提供监测值，原期望不变，并增加边界回归。

这是测试政策与工具阶段验收，不能替代 50/100 实际客户端容量验收。人数、600 秒窗口、95% 覆盖、120 秒连续、1800 秒浸泡与三组 A/B 要求保持，限流开放环境的结果单独标注。
