# S3 北美云端延迟测试基准

用户确认云服务器在北美并授权放宽本轮测试延迟线。新单独预登记 HTTP P95 5000 毫秒、实时命令 P95 8000 毫秒、健康检查 10000 毫秒；资源查询超时 5 秒、并行探测收集预算 11 秒。旧默认线和历史结果保留。

腾讯云实际执行 71/71 回归通过，包含新延迟精确边界、越界仍中止、健康失败仍中止、默认阈值不回写、协调器实际登记新参数，以及已有内存、所有权、采样和最终结算证据保护。

实际空闲云端本机健康检查中位约 10 毫秒，严格 SSH 路径中位约 1084 毫秒；IPQoS=none 小样本中位约 1037 毫秒，只作观测，不据此更换路径。Python 公网 HTTPS 探针 5 次均失败，不当作成功延迟样本；既有云端原生 HTTPS 检查另行保留。

500 MB 可用内存、HTTP／命令错误率 10%、50/100 实际人数、600 秒容量窗口、95% 覆盖、120 秒连续以及资产／回执／清理规则保持。本阶段只通过工具政策回归，容量需按新配置另跑。
