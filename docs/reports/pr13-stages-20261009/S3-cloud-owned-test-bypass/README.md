# S3 腾讯云测试专用解除限制配置

按用户要求，新增默认关闭的 RequestLimits:OwnedTestBypass。仅允许 Development、全回环监听、回环数据库连接，以及专用随机数据库与测试会话标记。正式环境或共享数据库误用会在启动前失败。

启用后四类 HTTP 接口改用无配额限流器，实时帧不受每秒配额约束，应用数据库连接池关闭以解除其并发连接上限。保留消息验证、事务和房间顺序、数据库自身容量与资源停止线。测试结束删除专属实例即可恢复默认测试配置；正式服务不启用此开关。

全部检查在腾讯云执行：232 个非 PostgreSQL 集成 Server 用例、197 个工具用例、3 个容器归属用例通过，实际 Godot HTTP／TLS 边界与回调隔离通过。新增测试同时验证默认限流仍有效、32 个同 IP 并发请求在启用时通过，以及正式环境等错误配置被拒绝。首次测试编译因缺少测试取消信号失败，修复后重跑 Server，首轮记录保留。

另修复 CI 对预期无效 TLS 证书错误的误判，仍要求证书确实被拒绝，并拒绝脚本或其他错误。此结论仅覆盖所列范围，完整 132 项和新版本 PostgreSQL 全套验收尚未关闭。
