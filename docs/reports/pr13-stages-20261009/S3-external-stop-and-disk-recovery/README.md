# S3 外部停止时序与磁盘恢复

两个本地真实客户端的复查在首个外层监控样本触及磁盘线：可用 14.978%，低于原冻结 15%。此时随机运行目录尚未创建，旧外层停止函数没有写出 STOP 文件；120 秒后强制回收进程，因此最终报告缺失，自然周期为 0，本地业务清理未知，该轮不验收。随后实际云端检查无遗留路由或资金占用，观察到两个断连后的结算；四个专属服务均清理。保留全部失败原文，不把云端最终回收当成客户端自然完成。

采集器新增可在随机运行目录创建前存在的 --stop-file，所有客户端和协调器共享该信号，并在最终报告记录其路径。腾讯云以最终暂存 Git 字节执行 110 项检查，110 通过、0 失败、0 跳过，包含提前停止不启动客户端和已有客户端收到同一停止信号的反例。

已完成云端终态测试的客户端副本逐一核对 2059 个 Git 对象及内容，可从 bf516e0 恢复；另备份和校验 29 个引擎生成 UID。确认没有活动测试挂载后移除该副本及派生导入缓存，实际释放约 1.9 GB，磁盘可用恢复约 18%。全部测试原始归档保留，未处理生产数据。
