# S3 专属 HTTPS/WSS 测试入口的私有中继前置检查

十人长时间 SSH 转发复跑中断后，测试驱动增加直接 HTTPS/WSS 模式，监控使用独立 HTTPS 路径。临时入口仅允许本轮测试来源，部署的 Caddyfile 保持原文件；启用与恢复按实际代理身份、运行配置哈希和中继进程身份执行。应用鉴权、协议和请求体限制保留，正式容量判据不放宽。

腾讯云实际启动私有网桥中继，对两个入口分别转发 2 MiB 二进制并验证完整往返和写方向半关闭；两个结果与发送哈希一致。单方向用户态缓冲为 64 KiB，产生背压时暂停读取，未启动按连接增长的工作线程。合计转发 8 MiB，原生进程退出 0，监听及测试线程清理完整。三个暂存 Git 输入与实际执行字节一致，原始档案六个文件逐项核验。

此项只证明私有传输前置条件。临时公网入口尚未启用、实际 HTTPS/WSS 游戏流程尚未验证；不记为十人自然周期、50／100 容量或全范围验收。先验证并保留生产配置恢复证据，再进行实际本地玩家测试。
