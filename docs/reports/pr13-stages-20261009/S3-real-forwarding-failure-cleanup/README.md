# S3 实际连接中断后的有界清理

本地十个 Windows Godot 客户端连接腾讯云专属实例，全部同时在线并处于对局后，验证进程身份及父进程，只终止本轮 SSH 转发进程一次。驱动约 0.3 秒后记录 ssh_forwarding_exited 并写入共享 STOP，随后建立一次仅供收尾的转发；未重启玩家或恢复负载。

十个客户端均经实际入口确认没有活动准备、未结束对局或未确认结算。本地进程与业务清理完整，无强制终止玩家或协调器。协调器仍退出 130、acceptance=false；停止结果不改为成功。本轮自然周期为 0，服务端十个收尾结算不算自然周期，更不作为 50／100 容量证据。

云端四个服务无重启或内存溢出。实际数据库只读复查显示：待结算资产占用 0、活动玩家 0、结算 10、账本 0；已知 Gold／Diamond 钱包前后核对一致。四个专属服务已按身份清理。全部本地、云端私有原始文件已归档并逐文件核验；原始匹配阶段快照拒绝单列保留。
