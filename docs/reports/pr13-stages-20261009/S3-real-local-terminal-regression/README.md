# S3 本地真实客户端终态复查

两个本地 Windows Godot 客户端分别使用 Mage／Priest，连接腾讯云专属实例，各自然完成 3 局，共 6／6 个周期。协调器退出 0；执行、证据、游戏流程、约定的小规模负载与清理均通过。没有业务拒绝或状态读取失败。性能维度不适用，该轮不证明 10／50／100 人容量。

服务端实际镜像与运行版本仍为 bf516e0，测试集成源为 9b385171；已验证服务端、协议和游戏客户端源码一致，保留镜像原始版本。测试临时放开 HTTP/IP／实时指令限流，数据库上限及池为 256，应用与数据库 CPU 配额解除，候选数值关闭。北美延迟线和 500 MB 内存线保持冻结。

结束后在实际测试数据库做只读检查：6 个结算、8 条账本记录、无遗留路由或资金占用。观察到的钱包货币核对一致；完整资产范围仍需单独验收。原始本地及云端档案均保留并核验哈希，四个专属服务已清理，生产旁路保持关闭。

远端 CI 仍发现三条回调隔离用例失败，正在核对其权威切局夹具；此小规模通过不替代 CI、其他故障矩阵、实验、渲染和容量验收。真人体验不在本次范围。
