# 账户身份显示原文修复

当前参考界面把姓名与UID传给通用文案翻译器，中文下会把账号名里的Priest／Mage／Fire／Gold等词替换。相同UID的真实PG姓名与原图已经逐项核对。旧大厅工厂也有同一调用问题。

仅修改main.gd和reference_ui.gd：现有标签帮助方法增加默认仍为true的本地化参数，只在两个账户身份调用处关闭翻译。服务器已规范化的displayName与UID原样显示，普通静态文案、职业名称、金币提示继续翻译；不改账户数据、身份校验或全局词库。

本地真实Godot前后各54个画面：3个已归档的真实测试PG身份＋6个符合既有trim/NFKC/2～20字符/无控制字符规则的显示夹具，中英文×960×540／1280×720／1920×1080。修复前参考界面24处姓名不符、旧工厂同组值检查24处不符；修复后两处均为0，姓名和UID数据不变，普通文案默认翻译仍通过，当前可见身份文字几何完整。前后原图及两个退出结果均保留，engine和stdout无资源或脚本错误，直接查看了真实Priest前后图及Gold中文窄屏图。

旧工厂只做隐藏组件的文本值兼容检查，不称为现行fallback工作流、排版或LIVE验收。显示夹具不新建账号，整个补测无登录、无网络、无新增对局；不重跑已完成矩阵。不将9个名字样本推成全Unicode字体覆盖。后续测试身份始终从Game／PG原文取得，不再从经过渲染的界面文字反推登录名。

原件和本地测试代码保留在G盘，Git只发布这份精简报告和正式UI修改。132任务396案例、77项正式待验收以及register／gate／MAIN均未改动。此修复补足已发现的UI缺陷，不代表整体验收完成。
