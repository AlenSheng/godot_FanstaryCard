# PR13 已通过画面测试的 G 盘归档后存储回收

完整来源与原图经 G 盘逐成员哈希及归档 CRC 核对后，再核对云端 3,403 个文件、实际成功结束的进程和无活动绑定，只清理 R8 独占测试副本、原图及临时输出，并按先清理挂载内文件再卸载的顺序回收该独占内存文件系统。
