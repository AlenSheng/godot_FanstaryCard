**T01满手：** 原B06正式计时分块S003/B0/S990100/CurrentRhythm，2.0秒实际出牌后手牌5，2.4秒下一次出牌前5、后4。原采样有四个100ms动作前full标记，含legal位；标志采样时点与动作后牌堆分列。实际默认20、无击杀／加牌、已抽未耗尽初库，依据原选牌／手牌账计得库9弃6；不是重放模拟。该短满手窗口**没有观测自然抽牌计时到期时的轮空**，不把实际5张偷换成已测完整轮空机制。

**T02控制：** 复用已获B03.1 EXPeriment支持的原9组（3策略×3seed）实际引擎控制：ApplyStun1500ms后真实Advance1ms，官方投影给1499ms，27份native观察均为stunned／remaining1499／无合法出牌，实际非法出牌0。源时钟在这些样本中受控保持，不伪称自然PVP或连续墙钟衰减。当前官方RoomSnapshotProjection在眩晕时移除battle.play_cards；本轮遵守该动作门，不用错误allowlist制造“选牌后仍可出牌”的误报。

**T03零蓄能：** 读取原B04默认Guardian/BOSS首段，真实出牌后空手、蓄能0，初始与该次连放无加速／蓄能增量／即时抽，后续原自然抽牌逻辑时钟标记为4秒（100ms tick）。保留原等待／蓄能时间线，不说是墙钟等待，也不拿4×5推算的20秒当已测五张耗时。

B06计时源的32个现有核心文件原样一致，BattleRoom去掉且只去掉14行B06_OBSERVE记录调用后与当前第33文件一致；额外Observer只把actor.Capture()快照传给只读计数／校验回调，不是另一套抽牌算法。不谎称带记录钩子的DLL与正式DLL逐字节相同。本轮未编译或执行新服务端代码。

当前Windows／OpenGL按三个实际状态各自职业×中英文×三尺寸补18格，复用烟测、其余17格。检查满手选中后仍可出牌、眩晕选中后禁用且显示由1499ms快照锚定的有界本机插值、空手零蓄能按4秒基础间隔显示进度且不出现实测20秒。原权威字段与UI本机anchor时钟分开。18格通过；37份各轮原PNG尺寸／SHA／CRC／解码通过，当前8图逐张看图，其余按native边界和值检查，不称所有37图都看完。无新增位图或ImageGen。

**投影边界：** 这些图不是原始公开协议重放。满手的进度条／怪物显示使用明确的补齐上下文；控制卡的可视化instanceID不是原GUID，实际牌类型／等级／手牌数及1499ms保留；零蓄能用私有原始出牌后状态投影。选牌后“正在计算效果”来自夹具未提供preview答复，不是测到网络卡死或已验收预览流程。本轮仅评等待／时长／动作门及所列布局，不给整屏所有数值或完整游戏效果授予验收。
