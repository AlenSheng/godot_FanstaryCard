# S4 当前控制输入集成

本轮原生 Domain 程序集与已验证的 B02/B07 当前房间输入相同；工具调用当前 Resolver、Room.PlayCards/Advance、目标对象、JSON 房间恢复和真实 PVP API。编译输入固定到 90713f2fc032178fdcb2cc26b479070bb822ccaa，49 个输入（48 个原生源文件与分析工具）逐字节匹配。原生 pilot、六类损坏控制及源码证据见 S3。

B02.4 的房间锁定/冻结合同为控制恢复提供输入；B03.4 整项尚未获最终验收，本轮仅使用其现行卡表、职业/武器数值和稳定运行态，不提前签署父任务或平衡性结论。三个职业六档武器分别作为 stratum，不用总体均值覆盖某一档失败。

当前工具不改变生产 Domain、协议、怪物计时或客户端预测；新增 union 单独统计目标实际增加的计时。同目标窗口由房间现有代码统一处理，没有新增递减或把独立目标/PVP 的窗混为一体。正式 RENDER 还需把首 seed 的实际房间向量对接当前界面，不能以现有离线客户端预测代替。
