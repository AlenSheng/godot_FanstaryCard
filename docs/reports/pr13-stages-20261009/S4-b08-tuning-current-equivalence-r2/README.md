# B08.3 当前选定源码对照 R2

腾讯云完成 36 组对照，每组旧源码和选定当前运行时各使用 3 对相同种子：共 432 场唯一原生 encounter。原 R1 已执行的 12 场在完整 G 备份后按原字节复用，R2 新执行 420 场。468 项对照破坏性检查和 288 项原有独立 oracle 检查全部拒绝错误数据。

每一行 encounter、每次出牌、配置、分母、结果、所有数值与选牌顺序均精确一致。只有预注册的 Selected.InstanceId、Actual.BattleId 和 Actual.AttackerId 使用语义稳定双射；Actual 的其余字段仍精确一致，完整矩阵已检查两个 encounter ID 名字空间不存在别名。36 份原始 equivalence JSON 和 72 份原生验证记录保留在本报告中。

原始 G 归档的 697 个成员已完成 SHA、CRC 与行数核验；通过输出随后按精确目录清理，pool hold 在关联同一 G 备份与清理证明后释放。R1 原失败记录及其云端原件保留。

原 systemd 服务已在成功退出后被垃圾回收。本阶段依据当前 boot 中唯一 invocation 的 PID 1 成功日志，以及原 runner、启动记录、输入和完整 G 归档的字节关联，证明真实成功终态。原始 terminal proof 和完整 journal projection 均保留；没有复建服务，也没有把 not-found 状态默认的零字段当作成功证明。G 传输 ACK 和 hold 释放记录引用同一终态证明 SHA。

本阶段只证明 51 个相关输入覆盖的有限当前源码对照。它不证明当前整棵 Git 树相同，也不把每组 3 对种子的对照称为 1000 对完整单元。原 216000 场完整实验仍属于 3a984bc64f5346b7f1d134926deec54be928a060，没有改写为当前源码实验。

B08.2 依赖尚未通过。本报告不提升 MASTER、MAIN、LIVE 或整体验收状态，也不改变卡组数值。原始 gzip 数据仍留在 G 盘，本报告仅发布原字节元数据与证据索引。
