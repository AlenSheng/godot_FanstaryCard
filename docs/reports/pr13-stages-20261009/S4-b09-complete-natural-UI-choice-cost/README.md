B09.4：完整自然界面选择成本与实验用例补源

腾讯云在 128 MiB、无网络、只读源和输入的独立容器中汇总全部 18 段的 3,078 条记录。与原始向量逐行核对命令字节、来源和权威状态；6 个无效证据输入与小样本尾部统计负控制通过。选择耗时包含渲染帧与模拟指针，部分条件还包含截图保存，按条件单列；受控响应等待发生在计时之后。它不代表真人决策、WAN 延迟或硬件帧率。实际样本只有 accept 和 skip，不声称实测 replace；重复渲染也不视为独立玩家或路线。

43 份完整源、运行器、输入、输出、systemd 和 journal 原件均已先存 G 盘，逐成员 SHA256 与 gzip CRC 通过，PID1 唯一调用成功已核对。原始资源/CPU/wall、实际 typed 请求与响应字节和经济物品保留在 36,000 条正式路线的原始冻结统计中，不与 UI 计时混算。

复核三项 EXPERIMENT 用例：cap5 的核心机会与额外请求/受控打断分别列出；所有 36,000 条路线均拒绝隐藏库顺序信息；九项配对比较未证明稳定收益，因此保留正式默认及 NoChange，低差异样本仍为 Inconclusive。当前 server/protocol 与编译产品源一致，路线驱动及统计算法字节未变。只补三项 EXPERIMENT 来源；RENDER 的隐藏顺序与默认关闭注入及其他来源/依赖仍待补，不将完整 UI 重放等同于这些未执行的注入，不升级 B09.4 或 MAIN。
