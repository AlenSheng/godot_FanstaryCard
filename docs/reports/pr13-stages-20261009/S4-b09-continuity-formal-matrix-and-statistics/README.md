# B09.4 完整自然路线矩阵与配对统计

三职业各完成三个 1000 组配对种子的预注册独立块；正式默认及 cap3/5/8 四臂共 9 单元、36000 条路线。全部真实 typed codec/router/RoomActor 请求、实例守恒和隐藏库顺序负控制通过。所有死亡、撤离及观察预算结局均保留在分母中，不筛选完成样本。本目录累计包含此前发布的子集，不增加重复样本。

冻结统计算法在腾讯云执行，每个主要比较 bootstrap 10000 次，固定随机种子 482999，公开 95% 配对区间及九项主要比较的 Bonferroni 家族区间。缺少单元、错误源、开发 smoke 混入、重复种子/容量行，以及零差异配对不得证明总体零效应等五项控制通过。法师和牧师低差异配对数量不足，保留 Inconclusive；守护者在这一固定机器人策略下，开启候选怪物卡池后的撤离率下降。具体计数、区间、经济物品、CPU/wall 和实际 typed 字节见原始 analysis.json。结论 NoChange_stable_benefit_unproven，正式默认保持关闭，不据此削弱守护者职业或声称真人策略表现。

九个原始单元和统计 R2 的完整证据已校验 SHA256、gzip CRC 和 PID1 唯一调用成功记录。此阶段确认完整原生矩阵和冻结统计执行，当前 Godot 对自然选择原始协议的界面读取、选择输入成本及完整 RENDER 仍待完成；B09.4/MAIN 不据此整体升级通过，真人不在此次范围。
