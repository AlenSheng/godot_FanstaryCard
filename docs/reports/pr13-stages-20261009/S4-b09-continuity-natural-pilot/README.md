# B09.4 自然路线开发试验云端验证

云端新程序编译零警告、零错误，复用 Domain、Contracts、Protobuf 的已通过原始程序集，核对其 Domain/Contracts/配置/协议输入与当前 release 等价。三职业 × 三种子 × 正式规则或 cap3/5/8，共执行 36 条合法自然路线，使用真实地图、原生 PVE 与击杀授予，不补怪物生命、候选或牌堆。36 行隐藏库顺序负控制和 194227 次实例守恒检查通过；实际记录 2268 次原生命令、134 次击杀、99 次怪物决定。

路线自然结果为 34 次死亡、2 次撤离；这是实际观测结果，不等于测试断言失败或成功通关率保证。受控 2 秒等待不是人类操作时间，原生命令次数也不是 HTTP 请求实测。该小样本尚未证明稳定收益，正式可选池开关仍关闭，结论保持 NoChange_pending。较大的正式预登记样本、完整经济与协议请求比较、当前 Godot 选择流程成本和 canonical EXPERIMENT/RENDER 仍待补齐，B09.4/MAIN 不升级为通过。

54 个原始成员包含完整冻结源、运行程序集、编译产物、RAW 与实际 PID1 唯一调用成功记录，已回存 G 盘并逐成员校验 SHA/gzip CRC。只清理通过组件的自身 tmpfs 和上传缓存，旧清理权限失败及连接前失败诊断保留，没有重复执行原生试验。cap 旧不确定调度经单元、journal、正确输出路径及预登记记录核对未曾启动，从下一未执行包续接，完整矩阵范围不变。
