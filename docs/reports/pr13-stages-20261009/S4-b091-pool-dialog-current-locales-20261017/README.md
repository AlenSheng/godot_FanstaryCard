# B09.1 怪物卡弹窗：当前画面与操作复核

当前 960×540 实拍确认原弹窗仍是灰底，和现有深青、金边面板不统一。本轮只改 `client/ui/monster_pool_view.gd`：复用现有主题、字体、正式暗红怪物卡及插画；扩大排版、并列操作、使用既有确认文案。候选卡预览直接归属弹窗，关闭后释放，不租用共享卡池；未重出或改动位图，不需 ImageGen，未改服务器、玩法数值、策略或默认怪物池开关。

同名活动卡原下拉列表难区分，本轮在活动列表和菜单使用一致序号，仅对客户端实际已知手牌中的实例显示既有“自己的手牌／Your Hand”文案。不推断隐藏牌库／弃牌位置。吸收、跳过、替换的原命令 payload、实例 ID 选择顺序和满池门禁保持原样，TEXT 表和搜刮弹窗函数未动。

先后两次同一原始受控协议画面的英文小窗口烟测保留。R2 315 个真实 Windows／OpenGL GUI 上下文的原 native ok=true 与全部原件保留；其中 270 为原始历史受控协议投影，45 是从已归档实际 native 满池记录投影的显式受控 UI 夹具，不是原始公开协议、自然实验或 LIVE。实际输入命中验证了满池先禁用吸收、下拉选择后启用、正确原始实例 ID、等待权威前不修改池数据，以及预览释放。

**语言记录错误与不得宣称的范围：** 初版观察器只记请求语言，没有核对实际语言。抽到日语画面仍为英文后，查当前 Palette／语言配置并执行独立 native API 核验：当前只启用 zh-CN 和 en，zh-TW／ja／ko 的设置请求被忽略，留在英文；三份代表 PNG 与英文原文件逐字节相同。因此原 315 条／原 ok 不覆盖，189 条额外语言请求不能当成繁中、日语或韩语验收通过，原五语计划范围未通过，产品未为此扩展语言。不能用“文件名写了 ja”当成真实日语画面。

当前可计的唯一现有语言矩阵范围为 126：108 个原帧投影和 18 个受控满池。后续同名卡标记只改活动列表非空分支，源码复核空列表分支等价，未重跑此前 270 个原帧上下文；只重新验证受影响的 18 个中英文／三尺寸／三职业满池场景，并在运行中断言实际语言等于请求语言。18 项全部通过，当前菜单另补一次打开画面核对，真实主题色为深青10272e、金边d3ae68。
