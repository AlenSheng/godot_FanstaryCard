# S4 北美容量 50 首轮

新 5／8／10 秒延迟基准下实际启动 50 个本机 Godot 客户端，采样最大在线／活跃均 12 人。发生登录、HTTP 重试超时及命令拒绝，协调器因无效工作负载中止，退出 3；没有达到 600 秒容量窗口，未通过。所有原始触发、非零退出、证据失败及清理失败判定保留。

内存未触及 500 MB，专属 IP／HTTP／实时／应用连接池限额关闭，数据库上限 256。实际检查数据库只分配 0.3 核，累计 CPU 节流 182349971 微秒，服务器日志出现数据库超时；没有 OOM。这说明资源配额确有影响，仍不能单独证明所有错误均由配额造成。后续预登记解除专属 CPU 配额和减缓启动，原失败不回写。

云端独立只读对账待处理冻结 0、活跃匹配玩家 0、结算 12、流水 0；四个专属容器已按完整身份移除。SSH 退出。云端归档与客户端全部原始文件哈希登记。客户端未知／失败的清理判定保持原样。
