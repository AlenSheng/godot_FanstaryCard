# 当前 release 运行镜像一致性核验

云端实际服务已切换到当前 release 产品代码的保护后镜像。内部和严格 HTTPS 健康检查返回 200，公网管理入口保持 404，原环境及临时测试限额逐项保持一致。PostgreSQL 容器未替换，切换前后玩家、钱包、金币、装备、账本、结算、待处理持有和活跃成员计数一致。

保护后构建及恢复备份兼容性检查已完成，401 份候选构建和私有备份原件保存在 G 盘并独立核对 SHA 与 gzip CRC。私有数据库备份和未保护程序集不上传 Git。原 stdin 传输中断经精确 PID、pipe_read、仅三条管道 FD、无锁和无切换意图证明代码尚未执行，关闭该输入进程后改用校验后的文件执行。第一次文件执行因现有锁文件打开权限在切换前终止；改为打开现有锁并取得同一排他锁后成功。原失败证据保留。

该阶段关闭运行镜像与当前产品代码的一致性问题；未据此关闭任何 LIVE 案例或整体验收。
