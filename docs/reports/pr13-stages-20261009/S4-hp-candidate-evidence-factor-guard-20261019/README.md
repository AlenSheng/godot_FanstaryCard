# HP 单因素候选的原始证据校验

报告读取器原先检查矩阵配对与文件哈希，却没有比较 HP 候选的已记录非 HP 输入。受控反例确认：改变非 HP 指纹、初始护盾、首轮预告、白名单外对照、单因素声明、白名单、删除指纹或没有减血量，8份无效副本仍被接受。

现在只对 HP 候选核对精确白名单及单因素声明；比较配对的非 HP 指纹、初始护盾、首轮预告和初始HP缩放上界；要求白名单外逐行内容除 Profile 外一致。原始 Error 行继续进入报告的失败分母，不伪造有效对照或丢掉失败样本。新增4个测试方法，并更新原负例以断言更早发生的拒绝分类。只修改报告工具和对应测试，不改正式战斗、配置、美术或UI。

受控副本9项检查通过：8个反例全部拒绝，原样18条历史对照可读取。相关37个测试方法通过组合证据完成验证：首次33方法有11条错误记录（10个方法，隔离副本无Git上下文）及1个旧分类断言失败；修正私有观察器的只读Git上下文及断言后，仅补验11个未合格方法，通过；原22个成功方法复用，另4个压缩原件兼容方法通过。没有宣称一次全新37项整套绿灯。首次完整stderr没有落盘且工具输出被截断，此限制、状态复核和与首次SHA相等的重建测试源码均保留；后续11+4方法有完整日志。
