# 当前公开重试路径：真实提交后的坏响应与PostgreSQL资产验收

当前release的解压失败终止修复在完整缓存Program＋独立PostgreSQL中补测：两个原生传输模式各执行坏gzip、未知编码和503重试，共6笔真实购买、10次实际购买POST。坏压缩只发1次并返回失败、不泄露成功data，后续真实钱包读取确认已提交；503、503、200三次请求保持相同幂等键与请求字节，原始后端每次实际200、body哈希相同，PG只留下1条购买、1条扣款账本和1瓶药水。10份原始请求、后端body及转发HTTP帧共30个对象逐项校验。

**原失败与修正条件：** 首轮旧账号余额合法为0、没有购买记录，成功提交的前置条件不成立。代理在保存具体拒绝状态前断言200，导致3次连接错误重试；该三次的具体原始HTTP拒绝码没有留存，不能编造为已观察400，也不当成客户端或资产缺陷。首轮original ok=false和全部原件保留。第二轮重新从原快照恢复，仅在新派生库中为两名已声明测试账号各设1000起始金币，并新增匹配的Gold账本，明确属于测试夹具，不是游戏自然收入。价格仍100、每人购买3次后余额900／800／700、药水净增3；原快照及生产资产未改。没有放宽幂等、资产正确性、重试次数或玩法限制。

代理修正为完整转发并记录真实拒绝，只有后端实际200才施加声明故障。26项本地基础控制和14项修正控制通过。首次原生加载启动器重复创建TEMP／TMP目录，在进程启动前退出，0HTTP／0Native；修正后首次实际加载通过。测试客户端源码随后保持同一字节，未重复加载或重跑已完成46次HTTP、8项正式契约、66项body／TLS边界及104项native回归。

本轮含原失败和本地控制共39次游戏API HTTP／100上限，3次Native／3上限（加载、首轮受控终止、第二轮成功），0新账号、0新对局。当前7个native输入和328个服务端输入源码文本核对；其中262个仅LF／CRLF不同，原始哈希分别保留，不声称原字节相同。缓存完整Program二进制哈希重新确认，无服务器源码／二进制上传或构建，客户端与故障代理始终本地运行，无部署或正式限流变更。
