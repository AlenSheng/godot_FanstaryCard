# 解压失败停止重试：当前公开请求路径复现与修复

修复实际客户端缺陷：底层已返回 BODY_DECOMPRESS_FAILED，但公开请求流程只把体积超限当终止错误，因 HTTP 状态为0继续重试。未修改源码的两个原生传输模式均复现：损坏gzip、截断空gzip和未知编码各发送3次POST，耗时约3.2–3.4秒。6个失败上下文、18次原始请求和原源码完整保留。

仅改 gateway.gd 中一处分类：解压失败和体积超限直接终止；该次attempt及logical遥测不再记入不存在的重试等待。新增正式契约覆盖GET／POST与两种终止错误，8项通过。没有改变3次尝试上限、30秒总deadline、0–200毫秒附加抖动或服务器Retry-After最低等待。
