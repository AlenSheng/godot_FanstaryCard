发现并复现了真实验收工具缺陷：同一账号三次ACK完成，其中一次先走弃战兜底，旧协调器仍退出0并接受正常smoke。新增完整链路反例后，当前版本退出1、不授予正常局通过；三次通用ACK完成数仍为3，正常完成2、兜底完成1。没有把成功ACK本身当作正常击杀。
