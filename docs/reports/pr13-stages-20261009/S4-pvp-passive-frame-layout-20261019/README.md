# PVP 本命面板布局验收（2026-10-19）

PVP 本命标题原先压到金色边框，法师和英文牧师说明会裁掉第三行。调整手牌标题与面板的空间，复用现有内边距；牧师按属性分行，法师将充能等级及其数值放在完整一行。正式修改仅在 `client/ui/exploration_view.gd`，沿用原有资源和金色／青色风格。

三职业 × 中英文 × 1920×1080／960×540，共 12 项布局与逐图验收通过。守护者 4 帧来自实际决斗状态回放；法师、牧师 8 帧为明确标记的文字排版夹具，不证明三职业实际战斗数值。最终只复测受各次文字换行影响的 4 帧，其余逐分支核对源码等价后复用。原始基线 12 项留白失败、第一候选 6 项裁字均保留，没有降低验收阈值。

牧师 4 帧图像本身通过，退出时的 Dummy 音频循环流警告也保留。另用现有音频停止接口执行 2 个启停周期、4 项独立清理控制，通过且退出无警告；未改正式音频。最终法师 4 帧渲染退出为 0，日志无警告。合法超出基础值的生命不夹断、不据此报异常；排版夹具继承的有效生命上限也不用于评价职业平衡。

本报告只确认 UI 布局修复。原始多人实测与完整容量验收的失败结论保留，整体验收仍未通过；官方 55 Accepted、67 Partial、10 Ready 不变，register、gate、MAIN 未改。此前完整 PCK 保留为旧源版本证据，后续当前版本容量复测须先刷新包含此 UI 修复的完整客户端包。
