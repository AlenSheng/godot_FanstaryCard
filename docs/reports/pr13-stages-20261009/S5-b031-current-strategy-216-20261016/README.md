# 三策略确定性与信息边界：216场实际Domain实验

54个三职业×三策略×两规则×三种子的控制上下文，真实战斗房间分别执行原状态及隐藏库序/随机状态改变后的出牌，共108个实际结算臂。54个上下文的原状态重复选择与隐藏信息对照均保持同一有序动作，策略选择不修改原状态；随后真实PlayCards均接受。

另108场完整O6合成入场实验直接调用当前CombatExperience.Simulate，复用未修改的Select、ShouldHold、Resolver和Deck。两次完整运行54对逐动作完全一致：对比有序卡ID/等级/覆盖元素、时刻、目标、结果及全部汇总。新房间生成的实例GUID不会伪称种子确定性，克隆状态对照则保留并比较相同实例GUID。976次策略实际出牌及108次对照出牌全部合法，原生异常与跳过均为零。

**完整108场只有40胜，68场60秒截止删失，删失没有算胜利。** 本实验验证正确性，不验证强弱收益、自然路线、数据库、LIVE、容量、渲染或真人。仅三种子/层，不推导统计精度。默认正式规则未激活候选，生产源文件前后45项哈希一致。

当前真实Numerics策略和Godot客户端策略是各自实现。本轮新实验覆盖前者，既有Godot OFFLINE证据保持独立；没有宣称本轮执行了Godot采样实验。隐藏改变范围是实际库序和持久RNG；未来路线/掉落不在该Select API输入中，不虚构这两类采样注入。
