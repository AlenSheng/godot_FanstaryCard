# S5 守护者当前逐等级配对实验

腾讯云使用当前真实 Domain/模拟器完成 18 个作业、432000 条完整逐对局记录，固定守护者 +0～+5、每档三个独立种子块、每层每块 1000 配对种子、O1/O6/E1/BOSS 和三种可见信息策略。零 Error，胜/败/删失均保留；每作业和整体预算保持，全部容器已回收。运行来源及程序集哈希保持真实记录。

每档每个构筑/怪物组/策略分别报告有效盾、盾溢出和胜率差的 95% 配对种子区间。+2/+4 的削弱仍存在；+1 结果没有掩盖其他等级，真实混合等级报告调用被拒绝，三条原实验检查通过。区间仅为描述性分层比较，不构成多重比较校正后的生产调参建议。

完整逐对局数据以可验证 gzip 留在云端，并备份本地 outputs；raw-manifest.json 同时列压缩字节数/SHA 和原始解压字节数/SHA。原生 summary 与压缩后的 summary 分别保留，没有删除样本或只用汇总冒充原始记录。压缩存储控制另在 S4。

本轮只证明隔离 PVE 遭遇层。完整合法路线、PVP、准备后 Boss、网络容量仍是各自未完成层；候选默认关闭，生产数值未调整，未签署总验收。严格失败和容量按用户决定暂缓，真人体验不在本次范围。
