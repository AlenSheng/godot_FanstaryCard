# S5 腾讯云默认限流试跑

服务器及独立数据库位于腾讯云，本机仅运行真实 Godot 玩家客户端。10 个客户端经同一 SSH 转发源访问，保留默认 IP 和实时指令限额。

首轮完成 0／30 次自然对局，接口 429 导致发压失败；第二轮将启动间隔调整为 20 秒，完成 8／30 次自然对局后按用户新指令停止，全部玩家进程和业务状态清理成功。两轮均未通过，不覆盖原有失败记录。云端只读对账及全部测试容器清理另有原始证据。

新一轮解除限制测试单独建档。50／100 人容量测试按用户决定继续暂缓，真人体验仍待补。原始客户端 JSONL、日志和数据库凭据留在私有输出目录，公共材料仅提供结论与哈希。
