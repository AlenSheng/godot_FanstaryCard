# S5 GDD 完整对局预算云端复验

10 名本机真实 Godot 玩家连接腾讯云专属实例，每人目标 3 局，原默认牌组、baseline_all_hand 与自然结算判据不变。独立预登记单局 1200 秒、总预算 3900 秒，原 600 秒失败保留。结果 22／30 自然对局，未通过；无法据此认定守护者问题已解决，也不继续增加对局截止。

未完成首局的守护者先打过两次石卫，分别约 362、381 秒，之后的金卫在约 263 秒处被截止。持续有有效出牌，无脚本兜底。全批 22 次正常 ACK 和 4 次清理 ACK 分开；按 STOP 时间分窗得到的 ACK 数包含提前进入清理的客户端，不能当成自然局数。

云端数据库只读对账：待处理冻结 0、活跃匹配玩家 0、结算 26、流水 8。四个专属服务容器已全部移除，SSH 已退出，另查实际玩家进程残留 0。原协调器的进程清理标记仍为 false，不覆盖该失败事实。

测试实例 IP 限流、实时配额和应用连接池限制关闭；资源安全线保留。期间另有有界的组件回归，记录其 CPU 限额，本次不据此作容量或配对性能结论。后续继续具体怪物长尾实验、渲染、容量及逐项验收。
