# S5 容量模式中的守护者有效进度核对

选取实际连接复用50人轮次中全部三个零正常周期守护者，逐行读取原始客户端JSONL。这三名客户端分别有11、10、8场权威战斗胜利，最长单场374.630、353.085、340.847秒，累计生命伤害分别1822、1774、1346。原始文件路径、大小与哈希，以及逐场观察、敌方生命变化与战斗摘要留存。

该轮使用active-hold容量工作负载，会延后主动撤离；零完成周期不能单独证明战斗停滞。此结论只解释这三个客户端，不能推出全部职业平衡、完整自然路线或容量通过。既有50人容量失败、100人中止、GDD1200截止结果均保留；没有调整卡组或怪物数值。
