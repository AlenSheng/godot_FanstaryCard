# S5 腾讯云守护者延长观察与真实客户端三局

10 个真实本地 Windows Godot 客户端连接腾讯云专属实例，4 法师、3 牧师、3 守护者，每人自然完成 3 局，共 30／30。客户端、测试计划和原始执行源码保持冻结；没有修改职业或卡组数值，候选配置仍关闭。

每局观察预算 2400 秒，总预算 7500 秒。本轮约 63 分钟结束，无资源守护停止、无强制终止进程。守护者 9 局均自然完成，其中 4 局从房间启动到结算确认超过 1200 秒，最长 1603.006 秒。因此原 600／1200 秒未完成结果保留为原观察窗口结果，不能据此认定死锁或必须削弱数值；本轮也不构成全路线平衡性验收。

北美延时基准保持 HTTP P95 5000 毫秒、指令 P95 8000 毫秒、健康检查 10000 毫秒，监控超时 10 秒。实测 HTTP P95 979 毫秒、指令 P95 593 毫秒，627 个 HTTP 成功结果、10 个取消结果、HTTP 错误 0。停止线为本机／云端各 500000000 字节可用内存，CPU 85%、可用磁盘 15%、actor wait P95 100 毫秒。专属 IP、HTTP、实时配额放开，应用和数据库 CPU 配额取消，连接复用及物理 PostgreSQL 连接预算均为 256；所有权、协议与业务约束继续生效。

本轮整体验收仍失败：保留 32 条 NOT_IN_ROOM 原始拒绝，其中 31 条房间快照读取、1 条出牌操作。已经核实的一条快照在结算通知之前发出、在房间路由移除后返回；不能把这条因果直接推广到全部拒绝，也不能把唯一出牌拒绝归为无害读取。客户端终态操作修复和独立复测继续进行，原失败结果不重写。

开测前和结束后均保存完整八张财务白名单原始表。账本从 0 条到 24 条，前后完整链差异均为 0；归因 NoAlertInObservedScope，仅适用于本轮数据库。30 条结算、未结算资产占用 0、活动玩家路由 0；四个专属测试服务按完整身份清理。本结果不替代余额终值、装备归属等全范围资产验收，也不修复上一轮已删除数据库的历史八条原始账链缺口。

50 个本地原始文件和 11 个云端原始文件已私有归档、下载并逐一核对哈希。汇总随 release 上传，原始客户端、财务和服务日志留存于受忽略的本地私有证据目录。此轮是 10 客户端功能检测；50／100 并发、公开 HTTPS／WSS、其余渲染／实验／审计层以及最终 MAIN 验收继续独立完成，真人体验排除本次范围。
