**真实缺陷及原失败：** R1只破坏客户端主终局JSON为7字节`{broken`，最终.status.json、原审计和正常清理均合法。旧`--run`仅核对状态/审计，没有独立读取主终局文件，实际误写evidence=Passed；运行整体仅因负载/时长不足exit1，不能当已检测出坏JSON。R1此LIVE案例记录为Failed，旧原件、正常写完未破坏的before-fault文件及原源码完整保留，不改写成Passed。
