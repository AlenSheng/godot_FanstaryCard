# UI 美术缓存回收修复（2026-10-16）

`Art.clear_texture_cache()` 原来只清空纹理字典。按钮销毁后，静态样式缓存仍持有 4 个 `StyleBoxTexture` 及其纹理，导致退出清理和内存回收入口无法释放这部分缓存。

现在先释放缓存样式，再清空纹理字典。活动按钮和面板仍持有自己的样式引用，因此不会因清理缓存而失去贴图。

隔离的 Godot 4.7.2 检查共 8 项通过：缓存建立与清空、活动按钮资源保留、销毁后的弱引用释放、缓存重建、面板副本独立性、重复清理及最后持有者释放。测试采用原始目录清单、卡牌目录及实际图片，不载入游戏自动加载节点，不运行战斗或网络，也没有重跑已完成的 72 条界面案例。

原始日志保留 Windows 证书库读取告警；本报告只确认上述资源生命周期断言，不声称运行日志全无错误。原云端回放的退出资源泄漏尚待专用诊断日志确认，本修复没有将它改判为通过。

逐项结果、来源 SHA 和原件位置见 `summary.json`。本次不修改 register、gate 或 MAIN，原始 132 项任务、396 个案例范围保持。
