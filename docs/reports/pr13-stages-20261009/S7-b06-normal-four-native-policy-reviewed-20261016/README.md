# B06 标准四席原生策略与恢复见证（2026-10-16）

7 个职业/初始武器等级组合 × 两种策略 × 3 个新种子，共 42 个四参与者原生房间。39 个自然进入 PVP，3 个在会合前因死亡结束；所有 14 个目标组合均有至少一次实际 PVP、三种恢复分支及真实出牌见证。共 117 次分支检查、109 次实际 PVP 出牌，另核对 689 份完整房间快照及 4,118 条类型化命令记录。

独立读器逐组复核公开配对规划、四参与者初始输入、选中实际对局、完整四参与者 JSON 往返、双方离开、出牌后检查点、断线后恢复、policy/configVersion 及二进制帧 16KiB 边界。配置 SHA 是独立的规范配置元数据；协议没有另一个 ConfigHash 字段。每个种子在同一组合的两种策略间初始输入匹配，但复用种子及三种派生分支不增加独立强度样本数。
