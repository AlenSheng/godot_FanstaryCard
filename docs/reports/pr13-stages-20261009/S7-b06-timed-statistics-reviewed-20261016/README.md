# B06 时间推进研究：计算与逐案例复核（2026-10-16）

86,400 场原件的冻结主统计、独立核对、采后出牌相位核对及第二套独立核对均完成。主口径核对 1,440 组均值/区间及 288 项精确检验，补充口径核对 432 组均值/区间及 432 项联合假设。52 份统计原件已完成 G 盘成员 SHA 与 gzip CRC 归档，没有重跑采样、B04 或 PG。

范围为法师合法默认二十张牌、6 个初始武器等级、4 类怪物、6 种策略，共 144 个分层；每层 300 个匹配种子，同一批种子在分层间复用。不能把它们当作 43,200 个互相独立的种子簇，也不能据缩样后的数量保证精度。所有启动记录均保留，报告结局为 43,924 次胜利、42,476 次死亡。

候选减基线的出牌后累计空手秒数在 60 秒窗口中有 96 层均值为正、48 层为零。单核策略的 24 层均值增量为 0.216—1.000 秒；三核/五核偏好策略的 48 层此增量为零，但 30 秒伤害均值均下降。冻结的补充 432 项校正输出中，7 层死亡边际差异拒绝相等，方向均为候选死亡更多：E1/build 的武器 0—5 级，以及 E1/basic 的武器 5 级。具体配对不一致数、点估计、点态区间及原报告校正 p 值见 `summary.json`。这些是固定分层的结果，不作为总体玩家分布的合并推断。

审查发现等待终点的解释限制：144 层均有过半配对差值按观测网格计为零。现有精确符号检验排除平局后，计算的是非零差值中的正负方向平衡，不能直接据其拒绝结果声称配对差值总体中位数升高；点态均值区间也不等同于全族均值显著性检验。此处保留冻结测试名称、数值及原报告，不用新统计替换结果。[NIST 对符号检验的定义](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/signtest.htm)列出排除平局后的方向计数；上述中位数限制是结合本次多数平局数据作出的数学解释。

原主口径是出牌前网格状态；补充口径从原件重建出牌后 100ms 网格区间，属于明确披露的采后计量核对，未替换原冻结结果。累计空手暴露不是精确连续时长；死亡或终局后的吸收处理保持原计划。历史 E4 样本没有混入。

12 个 B06 案例已经逐项记录本轮组件结论及缺口。原两席场景的 14 个未见证组合保留；独立四席目标子集已为这 14 组取得原生策略与恢复见证，不能混作统一强度矩阵。PVP 强度、合法同造价主题轴和正向复合资源闭环等范围仍未完成。已认证 WSS 属于其他 LIVE 条目的独立证据要求，不作为 B06.4 的新增门槛。本报告不自动修改 register、gate、MAIN，不开启候选。
