# B06 水调节与复合来源控制复核（2026-10-16）

为既有资源控制补充水调节轴。两组各144条新控制，共288条：4类怪物、6个初始武器等级、3个新种子、两种房间策略。采用可解锁并明确持有的合法二十张牌；先记录实际三张开手，再用相同二十个实例设置声明的五张手牌。自然时间暂停，最多128次动作。这是受控功能检查，不是默认开局、强度或全卡池实验。

288条来源与实例检查均通过，共1,294次实际 Room.PlayCards、9,058组原语前后快照、176条实际恢复核对及128次弃牌洗回见证。独立读器从原件核对144组配对初态、手牌上限、蓄能与即时抽牌来源：印刷蓄能实际入手638张、印刷即时抽2,116张、被动蓄能262张、被动即时抽0张；144次被动请求受到满手截断。请求数与入手数没有混计。

原有二十个牌实例在每例中守恒，另有68个实际击杀获得的 M-FIREBAT 实例单独入账。听潮、引流、澄波、沧海同调均有真实出牌记录。独立读器保留实际战斗在出牌前处理治疗/护盾、在抽牌原语后加入怪物奖励的行为。

水调节专选的144条在没有可选调节牌时停止，手中仍有其他牌，明确保留为 NoEligibleTuningUnfinished。复合全手出牌的144条均耗尽手牌。本轮没有观察到正向复合闭环，不能据此宣称全卡池无环，也不能将未结束样本改作完成。PR13-B06.3-T02 的完整实验仍未完成。
