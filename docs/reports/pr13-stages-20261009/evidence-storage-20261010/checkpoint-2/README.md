# PR13 云端空间清理与 G 盘归档

按用户要求，测试继续在腾讯云执行，原始数据和归档优先存放本地 G 盘。

本次逐文件核验 3 个已通过渲染阶段的本地归档，确认长度与 SHA256 后，清理云端对应画面、日志和采样副本。结果、输入清单和验收状态保留。实际磁盘净释放以 summary.json 为准，约 54 MB。

已结束 B08.1 渲染副本的导入缓存仅删除了一份共享副本，逻辑数据约 399 MB，但未释放相应物理空间，因此没有把这部分计入容量收益。原始资源保留。

新音频生命周期诊断和最近复验记录已归档 G 盘并核验全部成员。长场景退出告警与音频会话回归失败继续保留，未转为通过，也未清理其云端记录。

后续每批完成后使用临时云端目录，下载 G 盘，校验大小、SHA256 和归档成员后再清理已通过的云端副本。生产数据、配置与正在运行的测试不在清理范围。

另清理 3 份已在 G 盘完成 SHA256 和归档成员核验的临时压缩包，释放约 104 MB 云端内存存储空间。云端原始执行记录与收据保留。
