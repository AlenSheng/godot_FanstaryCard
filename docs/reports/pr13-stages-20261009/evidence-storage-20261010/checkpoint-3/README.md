# G 盘主存储与云端空间回收（检查点 3）

云端执行原生战斗和画面验收，每批完成后先将完整原始记录回传 G 盘，核对压缩前后 SHA256、CRC、记录数量和归档成员，再回收通过批次的云端副本。正在运行的输入、来源和执行摘要保留。

5 个旧归档副本回收了实际磁盘空间；静态材料的 493 个副本使用硬链接，只移除目录引用，没有虚报磁盘回收。7 个内容不同的报告保留。共享导入缓存只有 G 备份逐成员核验后才可移除，同一 inode 的副本也逐项限定范围。失败的原始结果保留。

正式战斗实验仍在分批进行，本文件只记录当时已经回传核验的批次，不表示完整实验完成。统计保留全部配对种子、结果类型和主要指标，使用带原始归档链的轻量输入；云端实际数据链校验及 4 个负对照通过。逐出牌原始数据继续保存在 G 盘。初次统计校验曾在文件未传齐时失败，改为整包传输后验证通过；没有改写原始失败记录。

当前验收寄存器及 MAIN 状态保持不变，真人体验和暂缓容量项目没有计为通过。
