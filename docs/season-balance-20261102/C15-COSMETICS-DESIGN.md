# C15 21至30级外观与称号细化

本设计按用户2026-11-05“采用上述候选，再细化外观与称号”的授权继续落实。前20级物品与数量沿已确认清单不变。以下是后续运行表、权益与展示的实施规格，尚未导入配置、发奖或验收。

## 逐级内容

21级：头像边框“寻迹者 / Trail Seeker”。青铜细边与低亮度寻途符纹，保留肖像中央透明区域。

22级：称号“遗迹寻者 / Relic Seeker”。仅作为玩家姓名旁的身份展示。

23级：收藏印记“初越门槛 / The First Threshold”。在赛季收藏页展示获得时间和来源季。

24级：卡背“寻途之印 / Waymark Seal”。用于已选卡背的展示，保持牌面、品质和战斗信息清晰。

25级：称号“遗境守望 / Veil Warden”。身份展示，不关联守护者职业或防御属性。

26级：头像边框“帷幕守印 / Veilbound Seal”。银色细边和青绿色内嵌符纹，使用与21级相同的外形和裁切规范。

27级：收藏印记“五行纪事 / Fivefold Chronicle”。展示五行纹章，不提供元素偏好、伤害或掉落加成。

28级：卡背“五行合契 / Convergent Sigil”。五行汇合纹样，复用24级的尺寸和安全区。

29级：称号“遗境绘图师 / Veil Cartographer”。用于探索成就身份展示。

30级：头像边框“遗境先行者 / Relicbound Pathfinder”。低亮度金色框与完整寻途符印，保留相同肖像安全区。主品牌继续使用Relicbound。

最终内容为3个边框、2个卡背、2个收藏印记和3个称号。资源采用现有深色石质、金属雕饰及符纹风格；显示不能遮挡昵称、血盾、意图、卡牌费用、品质或装备状态。资源导入后必须实际穿戴/选择并产出画面，只有权益记录不构成外观展示完成。

## 权益与来源

每一级按账号、原季、等级创建唯一待领权益。外观领取写独立的永久绑定所有权与来源流水；显示位置选择只接受已经拥有的资源ID。切换职业、登录、客户端重试或重新开服不重复领取，不允许交易、分解、制作或转换成金币/材料。

来源季与所有权分开保留。领取、选择及展示不修改战斗属性、永久卡级、专武、防具、配方或钱包。旧规则版本没有声明逐级奖励时，不根据新进程的当前表追造权益。重复拥有的资源不能通过重领获得替代货币。
