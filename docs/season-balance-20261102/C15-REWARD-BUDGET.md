# C15 季程独立投放核对

本项只核对候选14的确定性投放预算，不是实战路线、人群P50/P90、实际领取率或整服经济验收。原ZIP模型和历史结果保持原件；本新增来源名为`SeasonJourney`，不并入活动兑换预算。

前20级全部领取的上限为80原季绑定碎片、24永久勇士魂、8永久职业魂、4卡包共12张实际永久副本。四次职业魂奖励每次选择一个职业；81种选择顺序对应15种分配，三个职业合计始终为8。21至30级仅增加3头像框、2卡背、2收藏和3称号，没有金币、钻石、装备本体或红材料的直接投放。

待领权益不是已铸造资产。只有提交成功的首次领取计入新增来源；回滚、持久重放及重复拥有外观均不重复增加。碎片仍进入原季钱包，晚领不转给新季；永久魂、卡副本和外观保留来源季及配置账本。这些事务行为的运行证据见`C15-CLAIMS-BACKEND.md`，本算术检查不替代该证据。

30日季按每级门槛分别向上取整，20/30级累计经验分别为4901/8959；42日及60日均为6850/12525。奖励数量不随时长增加，报告中的日均量只是平滑参照，不保证玩家按日领取或完成。

按当前商店单位价格折算，主奖励影子购买成本为5888/3，即约1962.67金。这不是金币来源或已经发生的金币回收减少。固定购买频率场景不能再扣一次影子价；购买替代需结合实际存量、需求、整数包和共享日限另外验证。

复现入口为`tools/check_journey_reward_budget.py --output <新证据路径>`，输入固定到公开候选目录的SHA。最终核对14项通过，包含重复等级、增发数量、错误归属、职业选择、未知外观、卡包数量、概率和门槛篡改拒绝。首次工具草稿误以为公开目录带有`content_hash`字段，移除该工具假设，改按目录原字节SHA固定；没有更改产品数值。
