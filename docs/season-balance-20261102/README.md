1. A：冻结规则差异、赛季定义、永久与赛季资产域、版本和跨季边界。
2. B：法师单牌返牌、成功出牌 500ms 门禁、新季 PVE 最低伤害与真实领域回归。
3. C：六档难度、品质帽、季装、强化、印记、配方、机器人来源、红装周配额、双币市场、商店、活动、季程及主题配置。
4. D：使用真实 Resolver 与意图时钟验证三职业、合法卡组、怪物卡、PVP、路线、撤离、死亡重建和多资源账。

6. F：第 1/7/14 日边界与人群场景、最终配置与数据库/进程验证、远端集成、固定提交发布和重启后核验。

## 必须保持的约束

- 职业生命 70/80/100、护盾帽 35/40/50、20 张编组、5 张手牌、首张合资格牌定核、v0.70 逐张取整和怪物卡加入方式保持。
- 卡牌及专武永久 +5 帽保持；D0 至 D5 只将生效等级投影到 +0 至 +5，不改永久存档。永久专武总强化费用仍为 248 碎片。
- 旧季物品与余额归档，不删除或兑换成新季资产。钻石、勇士魂和职业魂永久保留。新规则不沿用旧 JSON 草案的卡组、卡牌和魂清零方案。
- 每逻辑服每自然周最多新造一件红装，周一上海时间 04:00 重置，不滚存。Boss、箱和活动共享配额，交易与遗物转移不新增数量。
- 单项实战模拟不超过 300 场；不再补测 100 人容量，不使用协议机器人替代原生 UI 或真实领域战斗证据。
- 本机负载进程继续保留 6 GiB 可用内存；云端继续保留 500 MiB RAM、3 GiB 磁盘及 5% 空间。不停止其他项目进程。
