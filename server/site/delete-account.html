ACCOUNT DELETION

删除账号

请在已登录的游戏客户端内发起删除请求。服务端会立即记录请求并进入 7 天冷静期；在冷静期内可取消，期满后账号、身份绑定和游戏进度将被永久删除。

流程

  1. 在游戏营地的账号区选择“申请删除账号”。
  2. 确认身份后提交请求，保存页面显示的请求状态。
  3. 冷静期内重新登录并选择“取消删除请求”，可保留账号。
  4. 冷静期结束后，后台任务会完成删除；完成后的账号不能恢复。

无法进入游戏

如果你无法登录，请通过支持页面提交账号删除申请。为保护账号，客服可能要求额外验证；不要在公开渠道发送登录令牌、密码或付款信息。

技术入口

已登录客户端使用 POST /api/v1/account-deletion 发起、GET /api/v1/account-deletion 查询、DELETE /api/v1/account-deletion 取消。所有接口都要求有效的 Bearer 会话，不接受匿名删除。
