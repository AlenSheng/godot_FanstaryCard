遠征は選択の連続

未知の世界に足を踏み入れましょう。いつ戻るかを選択します。

Relicbound (Veilhaul) はオンラインカード抽出ゲームです。キャンプで準備を整えてから、5つの要素によって形成された領域に入ります。カードデッキがペースを設定し、ルートがリスクを設定します。より深く進むという約束と、家に持ち帰ることができる成果を天秤にかけてください。

準備 · 戦闘 · 脱出

あらゆるステップで選択が求められます。

職業から始めます ↗
01 / 準備

カードは20枚。あなたのリズム。

共有カードをキャラクター クラス カードと組み合わせます。最大 5 枚のカードを手にしてリアルタイムでプレイします。プレイされたカードは捨て札置き場に入り、カードの山札がなくなると再シャッフルされます。

02 / 戦闘

共鳴。連携。そして勝利。

同じ属性のダメージカードをまとめて使うと共鳴が強まります。相反する属性の組み合わせは、ダメージの一部を減らして回復を強化します。魔物の耐性や相手の装備を見て手を選びましょう。

03 / 脱出

内側に進んでください。いつ出発するかを知ってください。

外輪からコアに向かって前進し、外層には後退しません。地図タイルを共有している旅行者は、決闘で衝突する可能性があります。採取ポイントを見つけてモンスターを一掃し、収穫物を持ち帰ってください。

04 / 戦利品

報酬を選択してください

マップタイル内のモンスターを一掃した後、装備、装備の破片、または即時回復を選択します。より深く進む前に、蓄えを増やすか回復してください。

05 / 所持品

限られたスペース。貴重な選択。

遠征パックでは持ち運ぶものが制限されます。安全なスロットは内容を保護します。死はあなたの5つの鎧と安全でない物資を他の旅行者の戦利品として残します。あなたのカードとクラス固有の武器はあなたのもののままです。

06 / 成長

戻ります。再構築します。再び出発します。

抽出した戦士とクラスのソウルを使用してカードを開発し、装備の破片を使用して装備をアップグレードします。次の遠征の前に、ゴールドを補充するか、プレイヤー マーケットで対象の装備を交換してください。

未知への備え

戦略を装備に。

特性セットを見る ↓

要素はダメージと耐性を形成します。効果の付加がカードデッキの戦略を形作ります。何を着るかを選択するときは、品質、アップグレード、セットボーナスのバランスを考慮してください。

5つの防具枠

アーマースロットは5つ。戦闘計画は 1 つです。

  • 01ヘルメット
  • 02胸部装甲
  • 03手袋
  • 04脚部防具
  • 05ブーツ

5 つのスロットすべてに任意の要素を含めることができます。各ピースは、その要素にダメージと耐性を提供します。セットには、要素の一致ではなく、効果の接辞の一致が必要です。

01 / 品質

品質と組み合わせ

鎧の品質は白、緑、青、紫からオレンジ、赤まであります。オレンジまたは赤の防具を合計 1 つまで装備します。紫色の装備には効果付加が付いている場合があります。オレンジと赤の装備は常にそうなります。

02 / 強化

シャードを使用してアップグレードする

防具は+5まで強化できます。+1〜+3には装備の欠片を使い、+4と+5にはそれぞれ同品質の装備も1つ必要です。強化した防具も死亡時に失うことがあります。

03 / 専用武器

キャラクタークラスに関連付けられた武器

深淵の杖、薪火の弦、山岳の盾はキャラクタークラスを自動的に装備し、生来の能力を強化します。死亡しても装備を解除したり紛失したりすることはありません。 +4 や +5 を含むすべてのアップグレードにかかる費用はシャードのみです。

3つの特性セット

特性を揃え、戦略を完成させよう。

穿刺、堅壁、活力 の 3 つのエフェクト アフィックスです。異なる要素が同じ接辞セットを形成できます。これらの効果は、設定された条件を満たした場合にのみ発動します。

3通常、接辞ピースが一致するとセットがアクティブになります
2一致するピースがオレンジまたは赤の場合、セットが有効になります
01 / 穿刺

穿刺

攻撃に直接ダメージを追加

攻撃に直接ダメージを追加し、攻撃型デッキを支えます。「穿刺」のダメージも、守護者の「堅壁」によるダメージ軽減を受けます。

02 / 堅壁

堅壁

より強力な防御を構築する

全職業のシールド獲得量を増やします。追加ダメージ軽減は守護者のみに適用され、シールドやHPが減る前に処理されます。

03 / 活力

活力

もっと回復してください。健康予備軍を築きましょう。

治癒を強化し、有効な体力の上限を基本最大体力の 140% まで引き上げます。すべてのキャラクタークラスが恩恵を受けることができます。最大シールド量は増加しません。

実践中のセット

木・火・土のように属性が異なっても、紫品質の「堅壁」装備3つでセットが発動します。紫2つでは発動しませんが、橙の「堅壁」1つと紫の「堅壁」1つなら発動します。

赤色の装備・共有サーバーの制限

赤い装備は高難易度遠征のレア報酬です。計画されたシステムでは、各サーバーは週に最大 1 つの赤いアイテムを生成し、すべてのプレイヤーとマップで共有できます。クォータは月曜日のサーバーのタイムゾーンの 04:00 にリセットされます。未使用の割り当ては引き継がれず、毎週赤いアイテムを受け取ることが保証されるわけではありません。

厄運 I 以上の難易度が開くと、混沌領域 のコアボスを倒すと、3 択報酬とは別に、サーバー クォータが利用可能な状態で追加の赤いアイテムを獲得する 0.4% のチャンスがあります。持ち帰った対象となる赤い装備は、プレイヤーマーケットでゴールドと交換することもできます。 厄運 の難易度と赤装備のドロップは現在のプロトタイプではまだ利用できません。

赤装備専用特性 · 今後のコンテンツ＋

赤装備には、再抽選できない専用特性が1つランダムで付きます。これらは今後の機能です。現在のプロトタイプでは、通常の赤装備入手は未実装です。

発見を取引しよう

あなたの発見を、誰かの次の戦略に。

オークションハウスで予備の装備の価格を自分で設定したり、カードデッキに合った装備を見つけたりできます。現在の取引ではゴールドが使用されています。高品質の装備を扱うダイヤモンドオークションハウスが計画されています。

01 / ゴールド市場

現在利用可能 · ゴールド取引

売り手が価格を決め、買い手は表示価格をゴールドで支払います。対象は持ち帰った装備のうち、装着しておらず未帰属のものです。余った戦利品を次の遠征の備えに変えましょう。

02 / 出品ルール

明確なルール。オープントレード。

リスティングは無料で、最大 8 つのアクティブなリスティングがそれぞれ 48 時間続きます。売れ残ったアイテムは在庫に戻ります。完了した販売では、売り手の収益から最低 1 ゴールドの 10% 手数料が差し引かれます。購入者は追加料金を支払いません。

03 / 今後の実装

計画中・ダイヤモンド取引

将来の計画では、金の取引を維持しながら、ダイヤモンドのリストとオレンジと赤の装備の決済を追加します。ゴールドとダイヤモンドのリストでは、それぞれの通貨が使用されます。ダイヤモンドオークションハウスはまだ利用できません。

何を取引できますか?

オークションハウスは対象となる装備を取引します。カード、戦士のソウル、クラスのソウル、装備の破片、遠征パック、ヘルスポーション、クラス固有の武器はリストできません。探検隊内に残っている物資も販売できません。
