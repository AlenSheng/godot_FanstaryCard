# 本地真实客户端测试连接

`local_player_driver.py` 接受已冻结的计划、专属云端运行记录和已导入的客户端源快照，执行十人自然周期或 50／100 人容量测试。客户端仍为本地 Windows Godot 进程。三份记录须与当前干净 Git 版本一致；客户端全部输入须匹配已验证哈希。

连接采用既有主机身份验证、5 秒保活和两个保活缺失预算。保活是连接稳定性措施，不保证消除跨洲网络中断，也不放宽 HTTP／指令／健康 5／8／10 秒、监控 10 秒或 500 MB 内存停止线。正式容量 CPU／磁盘／actor 红线继续由协调器按连续三窗口执行。

检测到转发进程退出或监控缺失时先写入共享 STOP 并保存原始停止原因。随后最多建立一次仅供现有客户端收尾的转发连接；不重启玩家、恢复负载或继续采样。新连接的进程、时间和用途单独记录；原协调器和原失败结果保持不变。最后按实际进程身份关闭转发，业务清理仍以客户端回报和云端只读审计为依据。

该恢复通路须以实际连接中断测试验证。实际测试仍须证明本轮自然周期、正式容量覆盖率及其余验收要求；恢复通路不能将失败轮次记为通过。

`--public-route` 使用云端已验证、仅允许测试来源的临时 HTTPS/WSS 路径，监控通过同一域名的独立 HTTPS 路径读取。此模式不创建 SSH 发压转发进程；所有停止规则和负载判据保持原值。已有 SSH 模式用于独立连接故障诊断。公网路径按完整身份、配置哈希和私有中继进程记录建立，测试结束后须恢复原 Caddy 运行配置并核验生产健康；部署的 Caddyfile 不修改。
